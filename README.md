# AI 기초체력훈련 커리큘럼

본 저장소는 K-디지털 기초역량훈련 과정 중 **AI 기초체력훈련** 커리큘럼 개발 프로젝트입니다.

## 프로젝트 개요

비전공자 및 직무전환 희망자를 대상으로, AI 도구 활용자에서 AI 응용 개발자로의 전환을 지원하는 체계적인 온라인 교육 콘텐츠를 개발합니다.

- **대상**: 비전공자, 직무전환자, 입문자
- **구성**: 총 27차시 (차시별 강의안 + 실습 노트북)
- **적용 분야**: 제조 분야 (제조 공정/품질 데이터 중심)
- **데이터**: KAMP(한국AI제조플랫폼) 기반 합성 데이터 및 공개 데이터셋

## 정부 필수 요건 (심사계획공고 기준)

모든 커리큘럼 콘텐츠는 다음 4개 역량 영역을 포함해야 함:

1. **AI 수리 (기초 수리)**: 확률, 통계, 선형대수 - 계산보다 개념 중심
2. **기술 역량**: 데이터 분석 도구로서의 Python과 SQL
3. **문제 기반 학습**: 공공/기업 실제 데이터 활용
4. **단계별 실습**: 문제 정의 - 데이터 분석 - 모델링 - 평가

**1차시 필수 포함 사항 (AI 윤리 및 보호 체계):**
- AI 윤리적 고려사항
- 데이터 보안 및 침해 방지
- 저작권 및 지적재산권
