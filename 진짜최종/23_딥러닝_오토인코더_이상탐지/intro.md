# 23차시: 딥러닝 응용 - 오토인코더 기반 이상 탐지

안녕하세요. 23차시 강의를 시작합니다.

지난 22차시에서는 Keras를 활용하여 MLP 모델을 직접 구현해 보았습니다. Sequential API와 Dense 레이어를 사용해 신경망을 구성하고, 역전파 알고리즘으로 가중치를 업데이트하는 원리를 학습했습니다. 또한 Dropout과 Early Stopping 같은 과적합 방지 기법도 실습했습니다.

이번 차시에서는 딥러닝의 특수한 구조 중 하나인 오토인코더를 학습합니다. 오토인코더는 인코더-디코더 구조를 가진 신경망으로, 입력 데이터를 저차원의 잠재 공간으로 압축한 뒤 다시 원래 차원으로 복원합니다. 이 과정에서 발생하는 재구성 오차를 활용하면 이상 탐지가 가능합니다. 정상 데이터만으로 학습한 모델은 비정상적인 패턴을 제대로 복원하지 못하기 때문입니다.

실습에서는 UCI Machine Learning Repository의 AI4I 2020 Predictive Maintenance 데이터셋을 활용하여 설비 고장 탐지를 수행합니다.
