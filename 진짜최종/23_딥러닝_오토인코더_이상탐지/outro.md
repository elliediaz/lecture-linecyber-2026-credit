# 23차시 마무리: 오토인코더 기반 이상 탐지

수고하셨습니다. 23차시 강의를 마무리합니다.

이번 차시에서는 오토인코더의 구조와 이상 탐지 원리를 학습했습니다. 오토인코더는 인코더가 입력을 잠재 공간으로 압축하고, 디코더가 이를 다시 복원하는 구조입니다. 핵심은 정상 데이터만으로 학습하여 정상 패턴을 기억하게 하고, 새로운 데이터의 재구성 오차를 통해 이상 여부를 판정하는 것입니다.

주요 개념을 정리하면 다음과 같습니다. 재구성 오차는 원본과 복원된 데이터 간의 MSE로 계산합니다. 임계값은 정상 데이터의 평균과 표준편차를 활용하여 설정하며, 오차가 임계값을 초과하면 이상으로 판정합니다. Keras에서는 Sequential 또는 Functional API로 구현하고, fit 함수에서 입력을 타겟으로 사용하는 것이 특징입니다.

다음 24차시에서는 CNN 기반 이미지 불량 검출을 다룹니다. 합성곱 신경망을 활용하여 제조 현장의 이미지 데이터에서 불량을 탐지하는 방법을 학습합니다. Conv2D와 MaxPooling2D 레이어의 원리와 이미지 데이터 전처리 기법을 익힐 수 있습니다.
