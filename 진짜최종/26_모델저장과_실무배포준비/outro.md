# 26차시 마무리

이번 차시에서는 머신러닝 모델을 저장하고 실무 배포를 준비하는 방법을 학습했습니다. joblib을 사용하여 모델을 파일로 저장하고 로드하는 방법, 압축 옵션을 활용한 효율적인 저장 방법을 익혔습니다. Pipeline을 구성하여 전처리와 모델을 하나의 객체로 통합함으로써, 배포 시 일관성을 유지하고 데이터 누수를 방지하는 방법도 다루었습니다.

핵심 개념을 정리하면 다음과 같습니다. 첫째, joblib.dump()와 joblib.load()로 모델을 저장하고 불러올 수 있습니다. 둘째, Pipeline은 전처리와 모델을 묶어 단일 객체로 관리합니다. 셋째, 시맨틱 버전 관리(MAJOR.MINOR.PATCH)와 메타데이터를 함께 저장하면 모델 이력 관리가 수월해집니다. 넷째, 배포 체크리스트를 통해 모델, 데이터, 환경, 테스트, 문서 영역을 체계적으로 점검해야 합니다.

다음 27차시에서는 Streamlit으로 웹앱을 만드는 방법을 학습합니다. 저장한 모델을 웹 인터페이스로 제공하여 사용자가 직접 데이터를 입력하고 예측 결과를 확인할 수 있는 서비스를 구축합니다.
