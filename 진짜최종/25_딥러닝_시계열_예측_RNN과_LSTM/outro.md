# 25차시 마무리

이번 차시에서는 시계열 데이터 처리를 위한 RNN과 LSTM을 학습했습니다. RNN의 순환 구조가 이전 시점의 정보를 은닉 상태로 전달하는 방식을 이해했고, 긴 시퀀스에서 발생하는 기울기 소실 문제를 확인했습니다. LSTM의 3가지 게이트(Forget, Input, Output)가 장기 의존성을 해결하는 메커니즘을 배웠으며, 간소화된 GRU와의 차이점을 비교했습니다. Predictive Maintenance AI4I 2020 데이터로 Sliding Window 기반 시퀀스 데이터를 준비하고, Keras LSTM 모델로 센서값 예측 실습을 진행했습니다.

다음 26차시에서는 딥러닝 모델 해석과 파인튜닝을 다룹니다. 학습된 모델이 어떤 근거로 예측을 수행하는지 SHAP과 LIME으로 분석하고, 모델 성능을 최적화하는 파인튜닝 기법을 학습합니다.
