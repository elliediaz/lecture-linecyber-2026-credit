# 27차시 부가자료

◎ 27차시

▶ 학습퀴즈 1
※ OX 선택형 문항

<문제>
REST API에서 POST 메서드는 서버에 새로운 데이터를 생성하거나 ML 모델에 예측을 요청할 때 사용한다.

<정답> O

<해설>
POST 메서드는 HTTP에서 데이터를 서버로 전송하여 새 자원을 생성하거나, ML 서비스에서는 센서 데이터를 전송하고 예측 결과를 받을 때 사용함. GET 메서드는 데이터 조회용으로 사용됨.

▶ 학습퀴즈 2
※ 4지 선다형 문항

<문제>
Streamlit 웹앱을 실행하는 명령어로 올바른 것은?

<보기>
① python app.py
② streamlit run app.py
③ uvicorn app:app
④ flask run app.py

<정답> 2번

<해설>
Streamlit 앱은 `streamlit run 파일명.py` 명령어로 실행함. 기본 포트는 8501이며, 브라우저에서 http://localhost:8501로 접속함. uvicorn은 FastAPI 서버 실행 명령어임.

▶ 학습정리하기

- 이번 차시에서는 REST API 기초부터 ML 모델 서비스 배포까지 학습함.

- HTTP 메서드(GET, POST)와 상태 코드(200 성공, 400 잘못된 요청, 500 서버 오류)의 의미를 이해함. requests 라이브러리를 활용한 API 호출을 실습하여 외부 서비스와 통신하는 방법을 익힘.

- Streamlit으로 사용자가 직접 조작하는 웹앱을 구축함. st.title(), st.slider(), st.button() 등 직관적인 함수로 인터랙티브한 대시보드를 만들 수 있음.

- FastAPI로 외부 시스템이 호출하는 API 엔드포인트를 구현함. @app.post() 데코레이터로 엔드포인트를 정의하고, Pydantic 모델로 입력 데이터를 검증함.

- Docker 컨테이너 배포 기초도 다룸. Dockerfile 작성과 이미지 빌드, 컨테이너 실행의 흐름을 이해함. 컨테이너를 활용하면 어느 환경에서든 동일하게 동작하는 배포가 가능함.

- 27차시에 걸친 전체 과정을 통해 데이터 수집부터 전처리, 탐색적 분석, 머신러닝 모델 학습, 딥러닝, 모델 해석, 그리고 서비스 배포까지 데이터 분석의 전 과정을 완성함.
