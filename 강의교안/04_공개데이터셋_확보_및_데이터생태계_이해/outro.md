# 4차시 마무리

이번 차시에서는 공개 데이터 생태계의 전반을 살펴보았습니다.

네 가지 주요 데이터 플랫폼의 특성과 활용 방법을 익혔습니다. 공공데이터포털(data.go.kr)은 정부 공식 데이터를 제공하며 신뢰성이 높습니다. AI 허브는 한국어 자연어, 이미지 등 AI 학습에 최적화된 고품질 라벨링 데이터를 제공합니다. Kaggle은 전 세계 데이터 과학자들이 활용하는 벤치마크 데이터와 경진대회를 제공합니다. UCI Repository는 학술 연구에 널리 사용되는 표준 머신러닝 데이터셋을 제공합니다.

데이터셋의 기본 구조와 핵심 용어들을 정리했습니다. 행(Row)은 레코드, 샘플, 관측치와 같은 의미이고, 열(Column)은 변수, 특성, 필드와 동일합니다. 독립변수(X)는 예측에 사용되는 입력이며, 종속변수(y)는 예측 대상인 타겟입니다. 학습 데이터(Training Set)는 모델 학습에, 테스트 데이터(Test Set)는 모델 평가에 사용됩니다. 데이터 활용 전에는 반드시 라이선스를 확인해야 합니다.

이로써 Part I(AI 윤리와 환경 구축)의 마지막 차시를 마무리합니다. 환경 설정부터 Python 기초, Pandas 활용, 그리고 데이터 확보까지 AI 프로젝트의 기반을 다졌습니다. 1차시의 윤리적 기반, 2차시의 Python 문법, 3차시의 데이터 처리 기술이 모두 연결되어 있음을 기억하시기 바랍니다.

다음 5차시부터는 Part II(데이터 전처리와 탐색적 분석)가 시작됩니다. 기초 기술통계량과 탐색적 시각화를 통해 오늘 확보한 데이터를 실제로 분석하고 의미 있는 패턴을 발견하는 방법을 학습합니다. 수고하셨습니다.
