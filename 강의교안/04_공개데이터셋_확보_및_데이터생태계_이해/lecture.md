## Part 1: 공공데이터의 정의와 활용

### 개념 설명

**공공데이터란 무엇인가?**

공공데이터법 제2조는 공공데이터를 다음과 같이 정의함.

> "공공데이터"란 데이터베이스, 전자화된 파일 등 공공기관이 법령 등에서 정하는 목적을 위하여 생성 또는 취득하여 관리하고 있는 전자적 방식으로 처리된 자료 또는 정보

핵심 3요소는 다음과 같음.

| 요소 | 설명 | 예시 |
|------|------|------|
| 생성 주체 | 공공기관 | 정부, 지자체, 공기업 |
| 형태 | 전자적 방식 | CSV, API, DB |
| 목적 | 공공 목적 | 통계, 행정, 서비스 |

공공기관에는 국가기관(행정부처·국회·법원), 지방자치단체, 공공기관(한국전력·건강보험공단 등), 지방공기업, 특수법인이 모두 포함되며 890개 이상의 기관이 데이터를 제공함.

**공공데이터의 종류**

| 유형 | 형식 | 접근 방식 | 활용 예 |
|------|------|----------|---------|
| 파일 데이터 | CSV, Excel, JSON | 다운로드 | 통계 분석 |
| 오픈 API | REST/SOAP | 실시간 호출 | 앱 연동 |
| 표준 데이터 | 공통 규격 | 다운로드/API | 주소, 법인 |
| 링크드 데이터 | RDF, LOD | SPARQL | 지식 그래프 |

> AI 학습에는 주로 **파일 데이터(CSV)** 또는 **API** 형태를 활용함

**공공데이터 제공 5대 원칙**

1. 무료 제공 - 실비 외 무료로 제공
2. 기계 판독 - CSV, JSON 등 개방형 포맷
3. 최신성 유지 - 정기적 업데이트 의무
4. 정확성 확보 - 오류 최소화, 품질 관리
5. 재이용 허용 - 상업적 이용 가능(별도 제한 시 명시)

### 제조업 활용 사례

| 프로젝트 | 사용 공공데이터 | 활용 방법 |
|----------|----------------|----------|
| 품질 예측 | 기상청 날씨 데이터 | 환경 요인의 품질 영향 분석 |
| 수요 예측 | 통계청 경기지수 | 외부 경제 지표 반영 |
| 물류 최적화 | 도로교통 혼잡도 | 배송 경로 예측 |
| 에너지 관리 | 전력거래소 요금 | 피크 시간 예측 |
| 설비 관리 | 공단 설비 이력 | 유사 설비 고장 패턴 분석 |

공공데이터는 무료이고 법적 근거가 있어 신뢰성이 높지만, 갱신 주기가 느릴 수 있고 AI용 라벨이 없는 경우가 많으며 개인정보 비식별화 여부를 확인해야 한다는 점에 주의해야 함.

## Part 3: 데이터셋 구조와 용어

### 테이블 형태 데이터의 구조

```
           열(Column) = 변수(Variable) = 특성(Feature)
              ↓         ↓         ↓         ↓
            ┌───────┬───────┬───────┬───────┐
            │온도   │습도   │압력   │불량여부│ ← 헤더(Header)
            ├───────┼───────┼───────┼───────┤
 행(Row)  → │85.2   │52     │1.01   │0      │ ← 레코드(Record)
 = 관측치   │87.5   │48     │1.03   │0      │   = 샘플(Sample)
 = 인스턴스 │92.1   │55     │0.98   │1      │   = 관찰(Observation)
            └───────┴───────┴───────┴───────┘
                 ↑                       ↑
             독립변수(X)              종속변수(y)
             = 입력(Input)           = 타겟(Target)
```

같은 개념을 문맥에 따라 다른 용어로 부른다는 점이 중요함.

- **행(Row)** = 레코드(Record) = 샘플(Sample) = 관측치(Observation) = 인스턴스(Instance)
- **열(Column)** = 변수(Variable) = 특성(Feature) = 속성(Attribute) = 필드(Field)
- **독립변수(X)** = 입력(Input) = 설명변수 = Predictor
- **종속변수(y)** = 타겟(Target) = 라벨(Label) = 반응변수

```python
# pandas에서의 표현
X = df[['온도', '습도', '압력']]   # 독립변수 (Features)
y = df['불량여부']                  # 종속변수 (Target)
```

### 변수의 데이터 타입

| 대분류 | 소분류 | 설명 | 예시 |
|--------|--------|------|------|
| 수치형 | 연속형 | 무한히 많은 값 | 온도(85.234°C) |
| (Numerical) | 이산형 | 정수값만 | 불량개수(0,1,2) |
| 범주형 | 명목형 | 순서 없음 | 라인(A,B,C) |
| (Categorical) | 순서형 | 순서 있음 | 등급(상>중>하) |
| | 이진형 | 두 가지만 | 불량(0/1) |

### 데이터 품질 이슈와 분할

| 용어 | 영어 | 설명 | 처리 방법 |
|------|------|------|----------|
| 결측치 | Missing Value | 값이 없음(NaN) | 삭제/대체 |
| 이상치 | Outlier | 비정상적 값 | 제거/변환 |
| 중복 | Duplicate | 동일 레코드 반복 | 삭제 |
| 불균형 | Imbalance | 클래스 비율 불균형 | 샘플링 |

ML에서는 전체 데이터를 훈련 세트(70%), 검증 세트(15%), 테스트 세트(15%)로 분할함. 훈련 세트로 모델을 학습하고, 검증 세트로 하이퍼파라미터를 튜닝하며, 테스트 세트는 최종 성능 평가에 한 번만 사용함.

### 실습 3: 데이터 구조 종합 확인 함수

```python
def check_dataset(df, name="Dataset"):
    """데이터셋 구조를 한눈에 확인하는 함수"""
    print("=" * 50)
    print(f"[{name}]")
    print("=" * 50)

    # 1. 기본 정보
    print(f"\n1. 크기: {df.shape[0]:,}행 × {df.shape[1]}열")

    # 2. 데이터 타입
    print("\n2. 데이터 타입:")
    for dtype, count in df.dtypes.value_counts().items():
        print(f"   {dtype}: {count}개")

    # 3. 결측치
    missing = df.isnull().sum().sum()
    print(f"\n3. 결측치: {missing:,}개 ({missing / df.size * 100:.1f}%)")

    # 4. 컬럼 목록
    print("\n4. 컬럼 목록:")
    for i, col in enumerate(df.columns):
        print(f"   {i + 1}. {col} ({df[col].dtype})")

    # 5. 수치형 요약
    print("\n5. 수치형 변수 요약:")
    print(df.describe().round(2))
    print("\n" + "=" * 50)


# 사용 예시
check_dataset(df, "제조 품질 데이터")
```

### 실습 4: 포털별 데이터 비교

```python
datasets = {
    "공공데이터포털": pd.read_csv("public.csv", encoding='cp949'),
    "AI 허브": pd.read_csv("aihub.csv"),
    "Kaggle": pd.read_csv("kaggle.csv"),
}

comparison = []
for name, d in datasets.items():
    comparison.append({
        "포털": name,
        "행": len(d),
        "열": len(d.columns),
        "결측률(%)": round(d.isnull().mean().mean() * 100, 1),
    })

print(pd.DataFrame(comparison).to_string(index=False))
```
