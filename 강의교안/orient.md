# 과정 오리엔테이션

안녕하세요, 제조데이터를 활용한 AI 이해와 예측 모델 구축 과정에 오신 것을 환영합니다.

이 과정은 총 27차시로 구성되어 있으며, Python 프로그래밍 기초부터 AI 모델 배포까지 전체 과정을 체험하실 수 있습니다. 5개 파트로 나뉘어 체계적으로 진행됩니다.

첫 번째 파트에서는 AI 윤리와 개발 환경을 구축하고, Python 기초와 데이터 다루기를 배웁니다. 두 번째 파트에서는 기초 통계량, 시각화, 가설검정, 데이터 전처리 등 통계 기반 분석 역량을 쌓습니다. 세 번째 파트에서는 분류, 회귀, 클러스터링, 시계열 예측 등 머신러닝 핵심 기법을 실습하고, 네 번째 파트에서는 MLP, 오토인코더, CNN, RNN까지 딥러닝 모델을 직접 구축합니다. 마지막 파트에서는 모델 해석 기법과 Streamlit, FastAPI를 활용한 웹 서비스 배포를 다룹니다.

각 차시는 25분 분량으로 이론과 실습이 함께 진행됩니다. Jupyter Notebook 또는 Google Colab에서 직접 코드를 실행하며 학습하게 되며, 모든 실습에는 Kaggle, UCI Repository, 공공데이터포털에서 제공하는 실제 제조 데이터를 활용합니다.

이 과정을 마치면 데이터 수집부터 전처리, 분석까지 데이터 분석 역량을 갖추고, 머신러닝과 딥러닝 모델을 직접 구축하는 AI 모델링 역량을 확보하며, 학습된 모델을 웹 서비스로 배포하는 실무 적용 역량까지 습득하게 됩니다.

프로그래밍 경험이 없어도 괜찮습니다. 기초부터 차근차근 배워나가며, 마지막에는 직접 만든 AI 모델을 웹 서비스로 배포하는 경험을 하게 됩니다. 그럼 1차시 AI 활용 윤리와 데이터 보호에서 만나뵙겠습니다.
