## 1차시: AI 활용 윤리와 데이터 보호

### 강의 도입

안녕하세요, 제조데이터를 활용한 AI 이해와 예측 모델 구축 과정에 오신 것을 환영합니다. 이번 차시는 전체 27차시 과정의 첫 번째 강의로, 앞으로의 학습 여정을 위한 중요한 기반을 다지는 시간입니다.

이번 차시에서는 AI 윤리와 데이터 보호에 대해 학습합니다. AI가 제조 현장에 본격 도입되면서 기술적 역량만큼이나 윤리적 기반이 중요해졌습니다. 실제로 데이터 편향으로 인한 불공정 판단, 기밀 정보 유출, AI 생성물의 저작권 분쟁 등 다양한 문제가 발생하고 있습니다. 이러한 문제들을 예방하고 올바르게 대응하기 위해서는 AI를 다루기 전에 먼저 윤리적 원칙을 이해하는 것이 필수적입니다.

이 강의에서는 AI 윤리 4대 원칙인 공정성, 투명성, 책임성, 안전성을 살펴봅니다. 공정성은 AI가 편향 없이 공평한 판단을 내리도록 하는 것이고, 투명성은 AI의 의사결정 과정을 설명할 수 있어야 함을 의미합니다. 책임성은 AI 시스템의 결과에 대한 명확한 책임 주체를 설정하는 것이며, 안전성은 개인정보와 기업 비밀을 보호하는 것을 뜻합니다. 또한 삼성전자 ChatGPT 기밀 유출 사건, Colonial Pipeline 랜섬웨어 공격 등 실제 데이터 보안 사고 사례를 분석하여 데이터 보호의 중요성을 체감합니다. AI 생성물의 저작권 문제와 윤리 점검 체크리스트 활용법도 함께 배웁니다.

앞으로 26주에 걸쳐 Python 프로그래밍부터 데이터 전처리, 통계 분석, 머신러닝, 딥러닝, 그리고 실무 배포까지 단계별로 학습하게 됩니다. 오늘 배우는 윤리적 기반은 이 모든 기술적 역량의 토대가 됩니다. 기술을 잘 다루는 것도 중요하지만, 그 기술을 올바르게 사용하는 것이 더욱 중요합니다. 함께 시작해 보겠습니다.

### 강의 마무리

이번 차시에서는 AI 활용의 윤리적 기반을 다졌습니다.

핵심 내용을 정리하면, AI 윤리 4대 원칙으로 공정성, 투명성, 책임성, 안전성을 배웠습니다. 공정성은 편향 없는 공평한 판단을, 투명성은 설명 가능한 AI를, 책임성은 명확한 책임 주체 설정을, 안전성은 개인정보와 기업 비밀 보호를 의미합니다. 이 네 가지 원칙은 AI 시스템을 개발하고 운영할 때 반드시 고려해야 하는 기준입니다.

또한 실제 보안 사고 사례를 통해 데이터 보호의 중요성을 확인했습니다. 삼성전자 ChatGPT 기밀 유출 사건에서는 내부 소스코드와 회의 내용이 외부 AI 시스템에 입력되어 문제가 되었습니다. Colonial Pipeline 랜섬웨어 공격에서는 미국 최대 송유관 시스템이 마비되어 비상사태가 선포되었습니다. 이러한 사례들은 기술적 보안만큼이나 사용자의 인식과 행동이 중요함을 보여줍니다.

AI 생성물의 저작권 문제도 다루었습니다. AI가 생성한 콘텐츠의 저작권 귀속, 학습 데이터의 저작권 침해 가능성 등 새로운 법적 쟁점이 등장하고 있습니다. 윤리 점검 체크리스트를 활용하여 AI 프로젝트 시작 전 윤리적 리스크를 사전에 검토하는 방법도 배웠습니다.

다음 2차시 Python 시작하기에서는 Anaconda와 Jupyter Notebook 환경을 설치하고, 첫 번째 Python 코드를 작성합니다. 변수, 조건문, 반복문 등 기본 문법을 익히며 본격적인 프로그래밍 학습을 시작합니다. 오늘 배운 윤리 의식을 바탕으로, 앞으로 기술적 역량을 체계적으로 쌓아가겠습니다. 수고하셨습니다.

## 2차시: Python 시작하기

### 강의 도입

안녕하세요. 이번 차시에서는 제조 AI 개발을 위한 핵심 도구인 Python 프로그래밍을 시작합니다.

지난 1차시에서 AI 윤리의 기본 원칙을 학습했습니다. 공정성, 투명성, 책임성, 안전성이라는 네 가지 원칙을 이해하고, 실제 보안 사고 사례를 통해 데이터 보호의 중요성을 확인했습니다. 이러한 윤리적 기반 위에서 이제 본격적으로 AI 개발 도구를 익혀 나갑니다.

Python은 AI와 데이터 분석 분야에서 90% 이상 사용되는 사실상의 표준 언어입니다. 직관적인 문법 덕분에 프로그래밍을 처음 접하는 분들도 빠르게 적응할 수 있고, NumPy, Pandas, scikit-learn, TensorFlow 등 풍부한 라이브러리 생태계 덕분에 아이디어를 빠르게 구현할 수 있습니다. 제조 현장에서도 설비 데이터 분석, 품질 예측, 이상 탐지 등 다양한 영역에서 Python이 활용되고 있습니다.

이번 차시에서는 먼저 Anaconda와 Jupyter Notebook 환경을 구축합니다. Anaconda는 데이터 과학에 필요한 라이브러리를 한 번에 설치해주는 배포판이고, Jupyter Notebook은 코드 실행 결과를 즉시 확인할 수 있어 데이터 분석에 최적화된 개발 환경입니다. 이어서 정수, 실수, 문자열, 리스트, 딕셔너리 등 Python의 기본 자료형을 배우고, f-string을 활용한 데이터 포맷팅 방법을 익힙니다. 조건문(if)과 반복문(for, while)으로 데이터를 처리하는 로직을 작성하고, 재사용 가능한 함수를 정의하는 방법도 실습합니다.

제조 현장의 생산량, 온도, 불량률 데이터를 직접 다루며 Python 기초를 체득해 보겠습니다. 오늘 배우는 기본기가 앞으로 모든 데이터 분석과 AI 개발의 출발점이 됩니다. 함께 시작해 보겠습니다.

### 강의 마무리

이번 차시에서는 Python 프로그래밍의 기초를 학습했습니다.

먼저 Anaconda와 Jupyter Notebook으로 데이터 분석에 최적화된 개발 환경을 구축했습니다. Anaconda는 필요한 라이브러리를 한 번에 설치해주고, Jupyter Notebook은 코드와 결과를 즉시 확인할 수 있어 데이터 분석 학습에 효과적입니다.

Python의 5가지 핵심 자료형인 정수, 실수, 문자열, 리스트, 딕셔너리를 익혔습니다. 정수와 실수는 수치 계산에, 문자열은 텍스트 처리에, 리스트는 순서가 있는 데이터 모음에, 딕셔너리는 키-값 쌍 저장에 사용됩니다. f-string을 활용한 데이터 포맷팅 방법도 배웠습니다. 이를 통해 변수 값을 문자열에 깔끔하게 삽입할 수 있습니다.

조건문(if-elif-else)으로 품질 등급을 자동 판정하는 로직을 작성했습니다. 반복문(for, while)으로 센서 데이터를 순회하며 분석하는 실습도 진행했습니다. 마지막으로 함수를 정의하여 재사용 가능한 코드를 작성하는 방법을 다루었습니다. 함수를 활용하면 동일한 로직을 여러 곳에서 호출할 수 있어 코드의 효율성이 높아집니다.

핵심 개념을 정리하면, Python은 직관적 문법으로 빠른 개발이 가능하고, Jupyter Notebook은 코드 실행 결과를 즉시 확인할 수 있어 데이터 분석에 적합합니다. if문과 for문은 데이터 처리 자동화의 기본이 됩니다.

다음 3차시에서는 NumPy와 Pandas 라이브러리를 활용하여 CSV 파일을 불러오고 실제 제조 데이터를 분석하는 방법을 학습합니다. 수고하셨습니다.

## 3차시: 제조데이터 다루기 기초

### 강의 도입

안녕하세요. 이번 3차시에서는 제조 데이터 분석의 핵심 도구인 NumPy와 Pandas를 학습합니다.

지난 2차시에서 Python 기초 문법을 익혔습니다. 변수와 자료형, 조건문과 반복문, 함수 정의까지 프로그래밍의 기본기를 다졌습니다. 이제 그 기반 위에 데이터 분석에 특화된 라이브러리를 활용하는 방법을 배웁니다.

NumPy는 빠른 수치 계산과 배열 연산을 가능하게 하는 라이브러리입니다. Python 기본 리스트로 5줄 걸리던 평균 계산이 NumPy로는 단 1줄로 가능해집니다. Pandas는 엑셀처럼 표 형태의 데이터를 효율적으로 다룰 수 있게 해주는 라이브러리입니다. CSV 파일을 불러오고, 데이터를 필터링하고, 그룹별로 집계하는 작업이 몇 줄의 코드로 처리됩니다. 이 두 라이브러리는 제조 현장의 센서 데이터 분석, 생산량 집계, 불량률 계산 등 실무 업무에서 필수적으로 사용됩니다.

오늘 배울 내용은 크게 세 가지입니다. 첫째, NumPy 배열의 생성과 연산 방법을 익힙니다. 배열 인덱싱, 슬라이싱, 벡터화 연산, 그리고 mean, std, max, min 등의 통계 함수를 다룹니다. 둘째, Pandas DataFrame의 구조와 활용법을 배웁니다. head, info, describe로 데이터를 탐색하고, loc과 iloc으로 원하는 데이터를 선택하는 방법을 익힙니다. 셋째, CSV 파일을 불러와 실제 제조 데이터를 분석하는 실습을 진행합니다. groupby를 활용한 라인별, 등급별 집계 방법도 함께 다룹니다.

이러한 효율성이 왜 데이터 분석에서 NumPy와 Pandas가 표준 도구로 자리잡았는지를 직접 체험하게 됩니다. 실무에서 바로 적용 가능한 기술을 함께 익혀 보겠습니다.

### 강의 마무리

이번 차시에서는 데이터 분석의 핵심 도구인 NumPy와 Pandas의 기초를 학습했습니다.

NumPy에서는 배열 생성, 인덱싱과 슬라이싱, 벡터화 연산, 그리고 mean, std, max, min 등의 통계 함수를 다루었습니다. 특히 조건 필터링과 np.where 함수를 활용하면 원하는 데이터를 빠르게 추출하고 변환할 수 있습니다. Python 기본 리스트보다 훨씬 빠른 연산 속도를 직접 체험했습니다.

Pandas에서는 DataFrame의 구조를 이해하고, CSV 파일 읽기, head(), info(), describe()를 통한 데이터 탐색 방법을 익혔습니다. 조건 필터링으로 원하는 행을 선택하고, groupby를 활용한 그룹별 집계 방법도 실습했습니다. 불량률 계산, 라인별 분석, 품질 등급 분류 등 실무에서 바로 적용 가능한 내용을 다루었습니다.

핵심 포인트를 정리합니다. loc은 레이블 기반 인덱싱, iloc은 위치 기반 인덱싱입니다. 조건문에서는 괄호와 &(and), |(or) 연산자를 올바르게 사용해야 합니다. 단일 열 선택은 Series를, 다중 열 선택은 DataFrame을 반환한다는 반환 타입 차이를 명확히 이해하는 것이 중요합니다.

다음 4차시에서는 공공데이터포털, AI 허브, Kaggle 등 다양한 플랫폼에서 공개 데이터셋을 확보하고 활용하는 방법을 배웁니다. 오늘 익힌 Pandas 기술로 실제 공개 데이터를 분석해보겠습니다. 수고하셨습니다.

## 4차시: 공개데이터셋 확보 및 데이터생태계 이해

### 강의 도입

안녕하세요. 이번 4차시에서는 공개 데이터셋의 세계를 탐색합니다.

지난 3차시에서는 Pandas를 활용하여 데이터를 불러오고 기본적인 조작 방법을 학습했습니다. DataFrame의 구조를 이해하고, 조건 필터링과 groupby를 활용한 집계 방법을 익혔습니다. 이제 실제로 분석할 데이터를 어디서, 어떻게 확보할 수 있는지 알아볼 차례입니다.

공개 데이터셋 활용 능력은 AI 프로젝트의 시작점입니다. 양질의 데이터를 무료로 확보할 수 있다면 학습 비용을 크게 절감하고, 다양한 도메인의 문제를 실험해볼 수 있습니다. 또한 데이터셋 구조와 관련 용어를 정확히 이해하면 이후 전처리와 모델링 단계에서 혼란 없이 작업을 진행할 수 있습니다.

이번 차시에서는 네 가지 주요 데이터 플랫폼을 다룹니다. 공공데이터포털(data.go.kr)에서는 정부 공식 데이터를 다운로드하는 방법을 배웁니다. 교통, 환경, 산업 등 다양한 분야의 신뢰할 수 있는 데이터를 활용할 수 있습니다. AI 허브에서는 고품질 라벨링 데이터를 확보하는 방법을 익힙니다. 한국어 자연어 처리, 이미지 인식 등 AI 학습에 최적화된 데이터셋이 제공됩니다. Kaggle에서는 전 세계 데이터 과학자들이 공유하는 벤치마크 데이터를 활용하는 방법을 다룹니다. UCI Repository는 머신러닝 연구의 표준 데이터셋을 제공하는 곳으로, 학술 논문에서 자주 인용되는 데이터를 확보할 수 있습니다.

또한 데이터셋의 기본 구조와 핵심 용어를 정리합니다. 행(Row)과 열(Column), 독립변수(X)와 종속변수(y), 학습 데이터와 테스트 데이터의 개념을 명확히 이해합니다. 데이터 활용 시 라이선스를 확인하는 방법도 함께 배웁니다. 3차시에서 익힌 Pandas 기술로 실제 공개 데이터를 분석해보겠습니다.

이번 차시에서는 기초 기술통계량과 탐색적 시각화의 핵심 개념을 학습했습니다.

## 6차시: 확률분포와 품질검정

### 강의 도입

안녕하세요. 오늘 6차시에서는 확률분포와 품질검정의 기초를 학습합니다.

지난 5차시에서 평균, 중앙값, 표준편차 등 기술통계량으로 데이터의 중심과 퍼짐 정도를 파악하는 방법을 배웠습니다. 히스토그램과 상자그림으로 데이터를 시각화하여 분포 형태를 확인하는 실습도 진행했습니다. 이번 차시에서는 한 단계 더 나아가, 데이터가 어떤 패턴으로 분포하는지 이해하고 이를 품질 관리에 활용하는 방법을 다룹니다.

제조 현장에서는 "이 측정값이 정상인가?", "생산량이 이상하게 높은데 실제로 문제가 있는가?", "불량률이 기준치를 벗어났는가?"와 같은 질문이 자주 발생합니다. 확률분포를 이해하면 이러한 질문에 감이 아닌 데이터 기반으로 답할 수 있습니다.

이번 차시의 핵심 내용은 세 가지입니다. 첫째, 정규분포의 개념을 이해합니다. 정규분포는 평균을 중심으로 좌우 대칭인 종 모양 분포로, 자연현상과 제조 데이터에서 가장 흔히 관찰되는 분포입니다. 둘째, 68-95-99.7 규칙을 배웁니다. 표준편차 1배, 2배, 3배 범위 안에 각각 68%, 95%, 99.7%의 데이터가 포함된다는 이 규칙은 품질 관리에서 정상 범위를 판단하는 핵심 기준이 됩니다. 셋째, Z-score를 활용한 이상치 탐지를 실습합니다. Z-score는 관측값이 평균에서 몇 표준편차 떨어져 있는지를 표준화한 점수로, 절대값이 2를 초과하면 이상치를 의심하고, 3을 초과하면 이상치로 판정합니다.

정규분포와 Z-score는 품질 관리의 기본 도구입니다. 오늘 배울 내용을 통해 측정값의 정상 여부를 객관적으로 판단하는 능력을 기르시기 바랍니다. 이 개념들은 다음 차시에서 배울 통계검정의 기반이 됩니다.

### 강의 마무리

오늘 6차시에서는 확률분포와 품질검정의 기초를 학습했습니다.

먼저 정규분포의 개념을 살펴보았습니다. 정규분포는 평균을 중심으로 좌우 대칭인 종 모양 분포이며, 평균(μ)과 표준편차(σ) 두 값으로 완전히 정의됩니다. 자연현상과 제조 공정의 많은 데이터가 정규분포를 따르기 때문에, 이 분포를 이해하는 것이 통계 분석의 기본입니다.

68-95-99.7 규칙을 통해 표준편차 1배, 2배, 3배 범위 안에 각각 68%, 95%, 99.7%의 데이터가 포함된다는 것을 배웠습니다. 이 규칙은 품질 관리에서 정상 범위와 이상치를 판단하는 핵심 기준이 됩니다. 예를 들어, 평균에서 3표준편차 이상 벗어난 값은 전체의 0.3%에 불과하므로 이상치로 의심할 수 있습니다.

다음으로 Z-score를 활용한 이상치 탐지를 실습했습니다. Z-score는 관측값이 평균에서 몇 표준편차 떨어져 있는지를 나타내는 표준화된 점수입니다. 계산 공식은 (관측값 - 평균) / 표준편차입니다. 일반적으로 절대값이 2를 초과하면 이상치 의심, 3을 초과하면 이상치 확정으로 판단합니다. 제조 현장에서 센서 값이 정상 범위인지 판단할 때 유용하게 활용됩니다.

다음 7차시 "통계검정 사례와 분석"에서는 t-검정, 카이제곱 검정, ANOVA 등 가설검정 방법을 학습합니다. 오늘 배운 정규분포와 Z-score 개념이 기반이 되므로 복습을 권장합니다. 수고하셨습니다.

## 7차시: 통계검정 사례와 분석

### 강의 도입

안녕하세요. 이번 7차시에서는 통계 검정 실습을 진행합니다.

지난 6차시에서 확률분포와 정규분포의 개념을 학습했습니다. 68-95-99.7 규칙을 통해 정상 범위를 판단하고, Z-score로 이상치를 탐지하는 방법을 익혔습니다. 데이터가 어떤 분포를 따르는지 이해하는 것은 통계 분석의 기초가 됩니다. 이번 시간에는 그 지식을 바탕으로 실제 데이터에서 의미 있는 결론을 도출하는 방법을 배웁니다.

통계검정은 제조 현장에서 매우 중요한 의사결정 도구입니다. "A라인과 B라인의 품질 차이가 우연인가, 실제 차이인가?", "공정 개선 후 불량률이 정말 줄었는가?", "새로운 원자재가 기존 것보다 성능이 좋은가?"와 같은 질문에 객관적으로 답할 수 있습니다. 눈으로 보이는 차이가 통계적으로 유의한 차이인지 검증하는 능력을 함께 키워보겠습니다.

이번 차시에서 다룰 핵심 내용은 다음과 같습니다. 먼저 가설검정의 기본 개념을 학습합니다. 귀무가설과 대립가설을 설정하고, p-value의 의미를 이해합니다. p-value가 0.05보다 작으면 통계적으로 유의한 차이가 있다고 판단하는 원리를 배웁니다. 이어서 t-검정과 ANOVA를 활용하여 집단 간 평균을 비교하는 방법을 실습합니다. 독립표본 t-검정으로 두 그룹을, ANOVA로 세 개 이상의 그룹을 비교합니다. 또한 카이제곱 검정으로 범주형 변수 간의 관계를 분석하는 방법을 다룹니다. 마지막으로 데이터가 정규분포를 따르지 않을 때 사용하는 Mann-Whitney U, Wilcoxon, Kruskal-Wallis 같은 비모수 검정도 배웁니다.

상황에 맞는 검정 방법을 선택하는 것이 핵심입니다. 변수 유형, 그룹 수, 정규성 여부에 따라 적절한 검정을 적용해야 올바른 결론을 얻을 수 있습니다. 함께 실습해 보겠습니다.

### 강의 마무리

이번 차시에서는 통계 검정의 핵심 개념과 다양한 검정 방법을 학습했습니다.

먼저 가설검정의 기본 원리를 익혔습니다. 귀무가설(H0)은 "차이가 없다"는 기본 가정이고, 대립가설(H1)은 "차이가 있다"는 검증하려는 주장입니다. p-value는 귀무가설이 참일 때 현재 데이터가 관측될 확률로, 이 값이 0.05보다 작으면 통계적으로 유의한 차이가 있다고 판단합니다.

모수 검정에서는 독립표본 t-검정으로 두 그룹의 평균을 비교하고, ANOVA로 세 개 이상 그룹을 비교하는 방법을 실습했습니다. ANOVA에서 유의한 차이가 발견되면 사후검정(Tukey HSD 등)으로 어느 그룹 간에 차이가 있는지 확인합니다. 카이제곱 검정으로는 성별과 불량 발생 여부처럼 범주형 변수 간의 관련성을 분석했습니다. 교차표(crosstab)를 만들고 기대 빈도와 관측 빈도의 차이를 검정합니다.

마지막으로 데이터가 정규분포를 따르지 않을 때 사용하는 비모수 검정도 배웠습니다. Mann-Whitney U는 두 독립 그룹 비교, Wilcoxon 부호 순위 검정은 대응 표본 비교, Kruskal-Wallis는 세 개 이상 그룹 비교에 사용됩니다.

핵심은 상황에 맞는 검정 방법을 선택하는 것입니다. 변수 유형(연속형/범주형), 그룹 수, 정규성 여부를 확인하고 적절한 검정을 적용해야 올바른 결론을 얻을 수 있습니다.

다음 8차시에서는 상관분석과 예측의 기초를 학습합니다. 두 변수 사이의 관계를 상관계수로 측정하고, 단순선형회귀를 통해 한 변수로 다른 변수를 예측하는 방법을 다룹니다. 수고하셨습니다.

## 8차시: 상관분석과 예측의 기초

### 강의 도입

안녕하세요. 이번 차시에서는 두 변수 간의 관계를 분석하고 예측하는 방법을 학습합니다.

지난 7차시에서 t-검정, ANOVA, 카이제곱 검정 등 다양한 통계 검정 방법을 배웠습니다. 그룹 간 차이가 통계적으로 유의미한지 검정하는 방법을 익혔습니다. 이제 한 단계 더 나아가, 변수들이 서로 어떤 관계를 맺고 있는지 분석해 보겠습니다.

상관분석과 회귀분석은 머신러닝 예측 모델의 기초가 되는 핵심 개념입니다. 제조 현장에서 "온도가 높아지면 불량률도 높아지는가?", "작업 시간과 생산량 사이에 관계가 있는가?", "특정 변수의 값을 알면 다른 변수를 예측할 수 있는가?"와 같은 질문에 답하기 위해 필요한 기법입니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 피어슨 상관계수를 통해 두 변수의 관계 강도와 방향을 수치로 표현하는 방법을 알아봅니다. 상관계수는 -1에서 +1 사이의 값을 가지며, 절댓값이 0.7 이상이면 강한 상관관계로 해석합니다. 둘째, 상관행렬과 히트맵으로 여러 변수 간 관계를 한눈에 파악하는 기법을 실습합니다. seaborn 라이브러리를 활용하여 시각적으로 분석하는 방법을 배웁니다. 셋째, 단순선형회귀의 원리를 이해하고, sklearn을 활용하여 실제 예측 모델을 구현해 봅니다. 최소제곱법으로 데이터에 가장 잘 맞는 직선을 찾는 원리를 학습합니다. 넷째, R-squared(결정계수)를 통해 모델의 설명력을 평가하는 방법도 함께 다룹니다.

중요한 점은 상관관계가 인과관계를 의미하지는 않는다는 것입니다. 도메인 지식과 함께 해석하는 습관을 기르시기 바랍니다. 이 차시를 통해 데이터 기반 예측의 첫걸음을 내딛어 보겠습니다.

### 강의 마무리

이번 차시에서는 변수 간 관계를 분석하고 예측하는 핵심 기법들을 학습했습니다.

먼저 피어슨 상관계수를 통해 두 변수의 선형 관계를 -1에서 +1 사이의 값으로 측정하는 방법을 배웠습니다. +1에 가까우면 강한 양의 상관, -1에 가까우면 강한 음의 상관, 0에 가까우면 선형 관계가 없음을 의미합니다. 절댓값이 0.7 이상이면 강한 상관, 0.4~0.7이면 중간 정도, 0.4 미만이면 약한 상관으로 해석합니다.

상관행렬과 히트맵을 활용하여 여러 변수 간 관계를 시각적으로 파악하는 실습도 진행했습니다. seaborn의 heatmap 함수로 변수들 사이의 상관관계를 색상으로 표현하면 패턴을 빠르게 파악할 수 있습니다.

단순선형회귀에서는 최소제곱법의 원리를 이해했습니다. 관측값과 예측값의 차이(잔차)의 제곱 합을 최소화하는 직선을 찾는 방법입니다. sklearn의 LinearRegression으로 예측 모델을 직접 구현해 보았습니다. R-squared(결정계수)를 통해 모델이 데이터를 얼마나 잘 설명하는지 평가하는 방법도 익혔습니다. R-squared가 1에 가까울수록 모델의 설명력이 높습니다.

핵심 포인트를 정리합니다. 상관관계가 인과관계를 의미하지는 않으므로 도메인 지식과 함께 해석해야 합니다. sklearn 사용 시 X는 반드시 2D 배열(.reshape(-1, 1))로 변환해야 합니다.

다음 9차시 "제조 데이터 전처리 (1)"에서는 결측치와 이상치를 처리하는 방법을 배웁니다. 데이터 품질을 높여 예측 모델의 정확도를 향상시키는 실무 기법을 함께 익혀 보겠습니다. 수고하셨습니다.

## 9차시: 제조데이터 전처리 1

### 강의 도입

안녕하세요, 오늘은 제조 데이터 전처리의 첫 번째 시간입니다.

지난 8차시에서는 상관분석을 통해 변수 간의 관계와 데이터의 통계적 특성을 파악하는 방법을 배웠습니다. 피어슨 상관계수로 관계의 강도를 측정하고, 단순선형회귀로 예측 모델의 기초를 다졌습니다. 이제 본격적으로 데이터의 품질을 개선하는 단계로 넘어갑니다.

"데이터 분석 프로젝트에서 전처리가 전체 작업의 60~80%를 차지한다"는 말을 들어보셨을 겁니다. 이는 과장이 아닙니다. 아무리 뛰어난 분석 기법이나 모델을 사용해도 입력 데이터의 품질이 나쁘면 결과도 나빠집니다. "Garbage In, Garbage Out"이라는 격언이 바로 이 원리를 설명합니다. 제조 현장의 데이터는 센서 오류, 입력 누락, 측정 장비 이상 등으로 인해 불완전한 경우가 많습니다. 이러한 데이터를 그대로 분석에 사용하면 잘못된 결론에 도달할 수 있습니다.

이번 차시에서는 결측치와 이상치라는 두 가지 핵심 문제를 다룹니다. 결측치는 센서 오류나 입력 누락으로 발생하는 비어있는 값입니다. isnull().sum()으로 결측치를 탐지하고, dropna()로 삭제하거나 fillna()로 대체하는 방법을 배웁니다. 결측 비율에 따라 어떤 전략을 선택해야 하는지도 함께 다룹니다.

이상치는 측정 오류나 실제 극단적 상황에서 나타나는 비정상적인 값입니다. IQR 방법은 사분위수를 활용하여 분포 가정 없이 이상치를 탐지하고, Z-score 방법은 정규분포에 가까운 데이터에 적합합니다. 가장 중요한 것은 이상치가 오류인지 중요한 신호인지를 판단하는 것입니다. 불량 예측 모델에서는 이상치가 핵심 정보일 수 있으므로 무조건 제거하면 안 됩니다. 이 기초를 탄탄히 다져야 다음 단계인 스케일링과 인코딩으로 나아갈 수 있습니다.

### 강의 마무리

오늘 결측치와 이상치 처리의 기본기를 익혔습니다.

핵심 내용을 정리합니다. 결측치는 isnull().sum()으로 탐지합니다. 결측 비율이 5% 미만이면 dropna()로 삭제를, 그 이상이면 fillna()로 대체하는 것이 일반적입니다. 대체 값으로는 평균, 중앙값, 또는 그룹별 평균을 사용합니다. 중앙값은 이상치에 덜 민감하여 많이 활용됩니다.

이상치는 IQR 방법과 Z-score 방법으로 탐지합니다. IQR 방법은 Q1 - 1.5*IQR 미만이거나 Q3 + 1.5*IQR 초과인 값을 이상치로 판정합니다. 분포 가정이 필요 없어 비대칭 데이터에 강건합니다. Z-score 방법은 절대값이 2 또는 3을 초과하는 값을 이상치로 판정하며, 정규분포에 가까운 데이터에 적합합니다.

가장 중요한 원칙은 이상치가 오류인지 중요한 신호인지를 판단하는 것입니다. 불량 예측 모델에서는 이상치가 핵심 정보일 수 있습니다. 예를 들어, 품질 불량이 발생한 시점의 극단적인 센서 값은 오류가 아니라 불량의 원인일 수 있습니다. 이런 경우 무조건 제거하면 중요한 정보를 잃게 됩니다. 또한 전처리 전후의 분포를 반드시 비교하여 의도치 않은 왜곡이 없는지 확인해야 합니다.

이상치 처리 전략으로는 삭제, 대체(평균, 중앙값), 경계값으로 대체(윈저화), 별도 플래그 생성 등이 있습니다. 분석 목적에 따라 적절한 방법을 선택해야 합니다.

다음 10차시 "제조 데이터 전처리 (2)"에서는 데이터 정규화와 표준화, 범주형 데이터 인코딩을 학습합니다. 이를 통해 전처리된 데이터를 머신러닝 모델에 입력할 수 있는 형태로 변환하는 방법을 배웁니다. 수고하셨습니다.

## 10차시: 제조데이터 전처리 2

### 강의 도입

안녕하세요. 이번 10차시에서는 제조 데이터 전처리의 두 번째 시간으로 스케일링과 인코딩을 학습합니다.

지난 9차시에서는 결측치와 이상치 처리를 통해 데이터 품질을 확보하는 방법을 학습했습니다. isnull()과 fillna()로 결측치를 처리하고, IQR 방법과 Z-score 방법으로 이상치를 탐지하는 실습을 진행했습니다. 이번 시간에는 전처리의 다음 단계인 스케일링과 인코딩을 다룹니다.

제조 현장의 데이터는 온도(섭씨 수십~수백도), 생산량(수천~수만 개), 불량률(0~1 사이 비율)처럼 단위와 범위가 서로 다른 변수들로 구성됩니다. 이러한 스케일 차이는 머신러닝 모델의 성능을 저하시키는 원인이 됩니다. 거리 기반 알고리즘이나 경사하강법을 사용하는 모델에서 특히 큰 영향을 미칩니다. 또한 라인명, 등급, 제품 유형 같은 범주형 데이터는 숫자로 변환해야만 모델에 입력할 수 있습니다.

이번 차시에서는 세 가지 핵심 내용을 다룹니다. 첫째, 스케일링 기법을 학습합니다. StandardScaler는 평균 0, 표준편차 1로 변환하는 표준화를 수행하고, MinMaxScaler는 0에서 1 범위로 변환하는 정규화를 수행합니다. 이상치가 있을 때는 RobustScaler가 효과적입니다. 둘째, 인코딩 기법을 배웁니다. 순서가 있는 범주에는 LabelEncoder나 OrdinalEncoder를, 순서가 없는 범주에는 OneHotEncoder를 사용합니다. 셋째, sklearn의 Pipeline과 ColumnTransformer를 학습합니다. 이 도구들을 활용하면 전처리부터 모델 학습까지 일관된 워크플로우를 구축할 수 있습니다.

가장 중요한 점은 fit은 반드시 학습 데이터만으로 수행하고, transform은 동일한 기준으로 모든 데이터에 적용해야 한다는 것입니다. 이를 통해 데이터 누수를 방지하고 재현 가능한 분석을 수행할 수 있습니다.

### 강의 마무리

이번 차시에서는 머신러닝 모델 입력을 위한 핵심 전처리 기법을 학습했습니다.

스케일링에서는 세 가지 방법을 배웠습니다. StandardScaler는 평균 0, 표준편차 1로 변환하는 표준화를 수행합니다. 대부분의 머신러닝 알고리즘에서 권장됩니다. MinMaxScaler는 0에서 1 범위로 변환하는 정규화를 수행하며, 이미지 데이터나 신경망에서 자주 사용됩니다. RobustScaler는 중앙값과 IQR을 사용하여 이상치에 강건한 스케일링을 수행합니다.

인코딩에서는 범주형 데이터를 숫자로 변환하는 방법을 익혔습니다. LabelEncoder와 OrdinalEncoder는 순서가 있는 범주(예: 등급 A > B > C)에 적합합니다. OneHotEncoder는 순서가 없는 범주(예: 제품 유형, 색상)에 적합하며, 각 범주를 0과 1의 이진 벡터로 변환합니다. 범주가 많으면 차원이 급격히 증가하므로 주의가 필요합니다.

가장 중요한 점은 fit은 반드시 학습 데이터만으로 수행하고, transform은 동일한 기준으로 모든 데이터에 적용해야 한다는 것입니다. 테스트 데이터에서 fit을 다시 수행하면 정보가 누출되어 모델 평가가 왜곡됩니다. ColumnTransformer로 컬럼별 전처리를 통합하고, Pipeline으로 전처리와 모델을 연결하면 데이터 누수를 방지하고 재현 가능한 워크플로우를 구축할 수 있습니다.

다음 11차시에서는 통계적 데이터 분석 종합과 한계를 다룹니다. 지금까지 배운 EDA 기법을 종합하고, 선형 모델의 한계를 인식하는 시간을 갖겠습니다. 수고하셨습니다.

## 11차시: 통계적 데이터 분석 종합과 한계

### 강의 도입

안녕하세요. 이번 시간은 Part II "기초 수리와 데이터 분석"의 마지막 차시입니다.

지난 10차시에서 스케일링과 원-핫 인코딩을 통해 제조 데이터 전처리를 마무리했습니다. StandardScaler, MinMaxScaler로 수치형 데이터를 변환하고, OneHotEncoder로 범주형 데이터를 처리하는 방법을 익혔습니다. 이제 정제된 데이터를 활용하여 지금까지 배운 모든 분석 기법을 종합적으로 적용해 봅니다.

이번 차시는 세 가지 측면에서 중요한 의미를 갖습니다. 첫째, 5-10차시에서 학습한 EDA 기법들을 실제 데이터에 체계적으로 적용하는 방법을 실습합니다. 기술통계, 시각화, 상관분석, 통계검정을 순서대로 연결하여 데이터에서 인사이트를 도출하는 워크플로우를 완성합니다. 둘째, 단순회귀를 넘어 여러 변수를 동시에 활용하는 중다회귀 분석을 배웁니다. 변수를 추가할 때 조정 R-제곱을 활용하여 실질적인 설명력 향상을 평가하는 방법을 익힙니다. 이 과정에서 발생하는 다중공선성 문제를 VIF(분산팽창계수)로 진단하는 방법도 함께 다룹니다. VIF가 10을 초과하면 해당 변수를 제거하거나 대안적 접근이 필요합니다.

셋째, 선형 모델의 한계를 직접 경험합니다. 비선형 관계나 복잡한 상호작용, 고차원 데이터에서는 선형 모델이 명확한 한계를 보입니다. 이러한 한계를 인식하는 것이 Part III 머신러닝으로 나아가는 동기가 됩니다.

이 차시가 Part II를 마무리하면서 Part III 머신러닝으로 나아가는 중요한 연결 고리가 됩니다. 통계적 기법의 강점과 한계를 모두 이해하고, 새로운 접근법이 필요한 이유를 체감하게 됩니다.

### 강의 마무리

이번 차시에서는 Part II의 마지막으로 통계적 데이터 분석을 종합하고 그 한계를 확인했습니다.

핵심 내용을 정리합니다. 첫째, 기술통계, 시각화, 상관분석, 통계검정을 체계적으로 연결하는 EDA 워크플로우를 실습했습니다. 데이터를 받으면 먼저 기술통계로 전체 분포를 파악하고, 시각화로 패턴을 확인한 뒤, 상관분석으로 변수 간 관계를 탐색하고, 통계검정으로 가설을 검증하는 순서를 따릅니다.

둘째, 중다회귀에서 변수를 추가할 때 조정 R-제곱(Adjusted R-squared)을 활용해 실질적인 설명력 향상을 평가하는 방법을 배웠습니다. 일반 R-제곱은 변수를 추가하면 항상 증가하지만, 조정 R-제곱은 불필요한 변수 추가 시 오히려 감소합니다.

셋째, VIF(분산팽창계수)가 10을 초과하면 다중공선성 문제로 변수 제거나 대안적 접근이 필요함을 확인했습니다. 다중공선성은 독립변수들 간의 높은 상관관계로 인해 회귀계수의 해석이 어려워지는 현상입니다.

넷째, 비선형 관계, 복잡한 상호작용, 고차원 데이터에서 선형 모델은 명확한 한계를 보입니다. 직선으로 표현할 수 없는 곡선 패턴이나 변수 간 복잡한 상호작용을 포착하지 못합니다.

이것으로 Part II "기초 수리와 데이터 분석"을 마칩니다. 통계적 기법은 데이터를 이해하고 해석하는 데 강력하지만, 예측 성능을 극대화하려면 새로운 접근이 필요합니다.

다음 12차시 "머신러닝 소개와 문제 유형"에서는 비선형 관계를 자동으로 학습하고 복잡한 패턴을 포착하는 머신러닝의 세계로 패러다임을 전환합니다. 수고하셨습니다.

## 12차시: 머신러닝 소개와 문제유형

### 강의 도입

안녕하세요. 오늘부터 Part III 머신러닝 모델링 파트가 시작됩니다.

지난 11차시까지 데이터 전처리와 탐색적 분석을 통해 제조 데이터의 특성을 파악하고 통계적 분석의 한계도 경험했습니다. 상관관계는 확인했지만 미래 값을 예측하거나 복잡한 패턴을 자동으로 찾아내기에는 한계가 있었습니다. 비선형 관계나 다수의 변수가 복잡하게 얽힌 상황에서는 기존 통계 기법만으로는 부족합니다.

이번 차시에서는 이러한 한계를 넘어서는 새로운 접근법인 머신러닝을 소개합니다. 머신러닝은 명시적으로 프로그래밍하지 않아도 데이터에서 스스로 패턴을 학습하는 방법입니다. 전통적 프로그래밍이 "규칙을 입력하면 결과가 나오는" 방식이라면, 머신러닝은 "데이터와 결과를 입력하면 규칙을 학습하는" 방식입니다.

이번 차시에서 다룰 핵심 내용은 네 가지입니다. 첫째, 전통적 프로그래밍과 머신러닝의 차이점을 비교합니다. 각각의 장단점을 이해하고 언제 머신러닝이 효과적인지 파악합니다. 둘째, 지도학습과 비지도학습의 개념을 학습합니다. 지도학습은 정답이 있는 데이터로 학습하고, 비지도학습은 정답 없이 데이터의 구조를 발견합니다. 셋째, 지도학습의 핵심인 분류와 회귀 문제를 구분하는 방법을 익힙니다. 분류는 범주를 예측하고, 회귀는 연속적인 숫자를 예측합니다. 넷째, sklearn 라이브러리의 기본 패턴을 학습합니다. fit-predict-score 패턴은 모든 모델에 공통으로 적용되므로, 한 번 익히면 다양한 알고리즘을 동일한 방식으로 활용할 수 있습니다.

데이터 준비가 완료된 지금, 본격적으로 예측 모델을 만들어 봅니다. 머신러닝의 세계로 함께 들어가 보겠습니다.

### 강의 마무리

오늘 Part III의 첫 시간으로 머신러닝의 기초 개념을 학습했습니다.

핵심 내용을 정리합니다. 머신러닝은 명시적 프로그래밍 없이 데이터에서 스스로 패턴을 학습하는 방식입니다. 전통적 프로그래밍이 "규칙을 코딩하면 결과가 나오는" 방식이라면, 머신러닝은 "데이터와 결과를 주면 규칙을 학습하는" 방식입니다.

지도학습(Supervised Learning)은 정답이 있는 데이터로 학습합니다. 입력(X)과 정답(y)의 쌍을 통해 둘 사이의 관계를 학습하고, 새로운 입력에 대해 정답을 예측합니다. 비지도학습(Unsupervised Learning)은 정답 없이 데이터의 구조를 발견합니다. 군집화, 차원 축소, 이상 탐지 등에 활용됩니다.

지도학습은 다시 범주를 예측하는 분류(Classification) 문제와 숫자를 예측하는 회귀(Regression) 문제로 나뉩니다. "이 제품은 양품인가 불량인가?"는 분류, "내일 생산량은 얼마인가?"는 회귀 문제입니다.

sklearn 라이브러리의 fit-predict-score 패턴은 모든 모델에 공통으로 적용됩니다. fit()으로 학습하고, predict()로 예측하며, score()로 성능을 평가합니다. 한 번 익히면 다양한 알고리즘을 동일한 방식으로 활용할 수 있어 매우 효율적입니다. train_test_split으로 데이터를 학습용과 테스트용으로 분리하는 방법도 배웠습니다.

다음 13차시에서는 회귀 모델의 확장인 다항회귀와 로지스틱 회귀를 다룹니다. 오늘 배운 sklearn 패턴을 활용하여 첫 번째 ML 모델을 직접 구현해 봅니다. 수고하셨습니다.

## 13차시: 회귀모델의 확장 - 다항회귀와 로지스틱회귀

### 강의 도입

안녕하세요. 이번 13차시에서는 회귀 모델의 확장에 대해 학습합니다.

지난 12차시에서 머신러닝의 기본 개념과 문제 유형에 대해 알아보았습니다. 전통적 프로그래밍과 머신러닝의 차이, 지도학습과 비지도학습의 구분, 분류와 회귀 문제의 차이를 이해했습니다. 또한 sklearn 라이브러리의 fit-predict-score 패턴을 익혔습니다. 이제 그 기초 위에서 실제 모델을 구현해 보겠습니다.

현실의 데이터는 단순한 직선 관계만 있는 것이 아닙니다. 온도가 높아질수록 불량률이 가속적으로 증가하거나, 변수들 간에 곡선 형태의 관계가 나타나는 경우가 많습니다. 8차시에서 배운 단순선형회귀는 이런 비선형 관계를 포착하지 못합니다. 이러한 비선형 관계를 다루기 위해 선형회귀를 확장한 다항회귀(Polynomial Regression)를 배웁니다.

이번 차시에서 다룰 핵심 내용은 두 가지입니다. 첫째, 다항회귀를 학습합니다. PolynomialFeatures를 활용하여 X, X의 제곱, X의 세제곱 등 거듭제곱 특성을 생성하고, 이를 통해 곡선 관계를 모델링하는 방법을 실습합니다. 차수가 높아지면 과대적합(overfitting)이 발생할 수 있으므로, 학습 점수와 테스트 점수의 차이를 확인하며 적절한 차수를 선택하는 것이 중요합니다.

둘째, "얼마나?"가 아닌 "무엇인가?"를 예측하는 분류 문제를 다룹니다. 로지스틱 회귀(Logistic Regression)는 시그모이드 함수를 통해 출력을 0에서 1 사이의 확률로 변환하고, 이를 기반으로 이진 분류를 수행합니다. 혼동 행렬, 정확도, 정밀도, 재현율, F1 점수 등 분류 평가 지표의 의미와 계산 방법도 함께 학습합니다. 특히 제조업에서는 불량을 놓치지 않는 것이 중요하므로 재현율에 주의를 기울여야 합니다. 제조 품질 분류 모델을 직접 구현해 보겠습니다.

### 강의 마무리

이번 차시에서는 선형회귀의 한계를 극복하는 두 가지 확장 모델을 학습했습니다.

다항회귀에서는 PolynomialFeatures를 활용하여 X, X의 제곱, X의 세제곱 등 거듭제곱 특성을 생성하고, 이를 통해 곡선 관계를 모델링하는 방법을 배웠습니다. 차수(degree)가 높아지면 더 복잡한 패턴을 표현할 수 있지만, 동시에 과대적합(overfitting)이 발생할 수 있습니다. 학습 데이터에서는 점수가 높지만 테스트 데이터에서 점수가 급격히 떨어지면 과대적합을 의심해야 합니다. 적절한 차수를 선택하는 것이 중요합니다.

로지스틱 회귀에서는 시그모이드 함수를 통해 연속값을 0에서 1 사이의 확률로 변환하고, 이를 기반으로 이진 분류를 수행하는 방법을 익혔습니다. 시그모이드 함수는 S자 곡선 형태로, 출력값이 0.5보다 크면 양성(1), 작으면 음성(0)으로 분류합니다.

분류 평가 지표로 혼동 행렬(Confusion Matrix), 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 점수의 의미와 계산 방법을 학습했습니다. 정밀도는 "예측한 양성 중 실제 양성 비율"이고, 재현율은 "실제 양성 중 예측한 양성 비율"입니다. 특히 제조업에서는 불량을 놓치지 않는 것이 중요하므로 재현율에 주의를 기울여야 합니다. 불량 1개를 놓치면 고객 불만과 비용 손실로 이어지기 때문입니다.

다음 14차시에서는 분류 모델의 첫 번째 주제로 의사결정나무를 학습합니다. 질문을 통해 데이터를 분류하는 트리 기반 알고리즘의 원리를 알아보겠습니다. 수고하셨습니다.

## 14차시: 분류모델 - 의사결정나무

### 강의 도입

안녕하세요. 이번 14차시에서는 첫 번째 분류 모델인 의사결정나무(Decision Tree)를 학습합니다.

지난 13차시에서는 다항회귀와 로지스틱 회귀를 통해 비선형 관계 모델링과 분류 문제 해결 방법을 배웠습니다. 로지스틱 회귀는 확률 기반으로 범주를 분류하는 강력한 기법이지만, 모델의 결정 과정을 직관적으로 이해하기 어렵다는 단점이 있습니다. 오늘은 전혀 다른 접근 방식으로, 질문을 통해 데이터를 분류하는 트리 기반 모델을 살펴봅니다.

의사결정나무는 "스무고개"처럼 예/아니오 질문을 반복하여 최종 결정에 도달하는 알고리즘입니다. "온도가 80도 이상인가?", "습도가 60% 이하인가?"와 같은 질문을 거쳐 최종적으로 양품 또는 불량을 판정합니다. 이 과정이 나무 구조로 표현되기 때문에 의사결정나무라고 부릅니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 트리 구조의 기본 개념을 이해합니다. 루트 노드, 내부 노드, 리프 노드의 역할과 분할 과정을 학습합니다. 둘째, 좋은 분할을 판단하는 불순도와 지니 계수를 배웁니다. 지니 불순도는 데이터가 얼마나 섞여있는지를 측정하며, 0이면 완전히 순수하고 0.5이면 가장 불순한 상태입니다. 셋째, 분할의 효과를 측정하는 정보 이득(Information Gain)을 학습합니다. 트리는 정보 이득이 가장 큰 분할을 선택합니다. 넷째, sklearn의 DecisionTreeClassifier를 사용하여 모델을 학습하고, plot_tree와 export_text로 트리 구조를 시각화하여 해석하는 방법을 실습합니다.

의사결정나무의 가장 큰 장점은 해석 가능성입니다. 모델이 왜 그런 결정을 내렸는지 트리 구조를 따라가면 명확하게 이해할 수 있습니다. 제조 현장에서 불량 원인을 분석하거나, 의사결정 근거를 설명해야 하는 상황에서 특히 유용합니다.

### 강의 마무리

이번 14차시에서는 의사결정나무의 원리와 실습을 진행했습니다.

핵심 개념을 정리합니다. 의사결정나무는 질문 기반으로 데이터를 분류하는 알고리즘입니다. 루트 노드에서 시작해 각 내부 노드에서 질문을 던지고, 리프 노드에서 최종 분류 결과를 출력합니다.

지니 불순도(Gini Impurity)는 데이터가 얼마나 섞여있는지를 측정합니다. 0이면 완전히 순수하고(한 클래스만 존재), 0.5이면 가장 불순한 상태(두 클래스가 반반)입니다. 정보 이득(Information Gain)은 분할로 인해 불순도가 얼마나 감소했는지를 나타내며, 트리는 정보 이득이 가장 큰 분할을 선택합니다.

과대적합을 방지하기 위해 여러 파라미터로 트리 성장을 제한해야 합니다. max_depth는 트리의 최대 깊이를 제한하고, min_samples_split은 분할에 필요한 최소 샘플 수를 지정하며, min_samples_leaf는 리프 노드의 최소 샘플 수를 설정합니다. 이러한 제한 없이 트리를 성장시키면 학습 데이터에 과하게 맞춰집니다.

plot_tree()와 export_text()를 통해 트리 구조를 시각화하고, feature_importances_로 어떤 특성이 분류에 중요한지 확인하는 방법도 배웠습니다. 특성 중요도는 각 특성이 불순도 감소에 기여한 정도를 나타냅니다.

다음 15차시에서는 분류 모델 (2): 랜덤포레스트를 학습합니다. 의사결정나무 하나는 불안정하고 과대적합에 취약하다는 단점이 있습니다. 랜덤포레스트는 여러 개의 트리를 앙상블하여 이러한 약점을 보완하고 성능을 향상시킵니다. 수고하셨습니다.

## 15차시: 분류모델 - 랜덤포레스트

### 강의 도입

안녕하세요. 이번 15차시에서는 랜덤포레스트에 대해 학습합니다.

지난 14차시에서 의사결정나무를 배웠습니다. 의사결정나무는 직관적이고 해석하기 쉬우며, 질문을 통해 데이터를 분류하는 과정이 명확하게 보입니다. 하지만 단일 트리는 데이터가 조금만 바뀌어도 결과가 크게 달라지는 불안정함이 있었습니다. 또한 학습 데이터에 과하게 맞춰지는 과대적합(overfitting) 문제도 발생합니다. 이러한 단일 트리의 한계를 어떻게 극복할 수 있을까요?

해답은 집단 지성에 있습니다. 한 명의 전문가보다 여러 전문가의 의견을 모으면 더 정확한 판단을 내릴 수 있듯이, 여러 개의 나무를 모아 숲을 만들면 훨씬 안정적인 예측이 가능합니다. 이것이 바로 앙상블 학습의 핵심 아이디어입니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 앙상블 학습의 개념을 이해합니다. 여러 모델의 예측을 결합하여 단일 모델보다 나은 성능을 얻는 방법입니다. 둘째, 배깅(Bagging) 기법을 학습합니다. 부트스트랩 샘플링으로 다양한 데이터셋을 만들고 병렬로 학습한 뒤 결과를 투표로 결합하는 방식입니다. 셋째, 랜덤포레스트의 작동 원리를 살펴봅니다. 배깅에 특성 랜덤 선택을 추가하여 트리들의 다양성을 더욱 높입니다. 각 분할에서 전체 특성이 아닌 무작위로 선택된 일부 특성만 고려합니다. 넷째, OOB(Out-of-Bag) 에러를 통해 별도의 검증 세트 없이도 모델 성능을 추정하는 방법을 학습합니다.

sklearn의 RandomForestClassifier를 활용한 실습을 통해 의사결정나무와 랜덤포레스트의 성능 차이를 직접 확인해 보겠습니다. 나무를 모아 숲을 만드는 원리를 체험하게 됩니다.

### 강의 마무리

이번 차시에서는 랜덤포레스트를 통해 앙상블 학습의 강력함을 확인했습니다.

핵심 내용을 정리합니다. 앙상블(Ensemble)은 여러 모델의 예측을 결합하여 단일 모델보다 나은 성능을 얻는 방법입니다. "세 사람이 모이면 문수의 지혜"라는 말처럼, 여러 모델의 의견을 종합하면 더 정확한 예측이 가능합니다.

배깅(Bagging, Bootstrap Aggregating)은 부트스트랩 샘플링으로 다양한 데이터셋을 만들고, 각 데이터셋으로 모델을 병렬 학습한 뒤 결과를 투표로 결합합니다. 부트스트랩 샘플링은 원본 데이터에서 중복을 허용하여 추출하는 방식입니다.

랜덤포레스트는 배깅에 특성 랜덤 선택을 추가하여 트리들의 다양성을 더욱 높입니다. 각 분할에서 전체 특성이 아닌 무작위로 선택된 일부 특성(보통 sqrt(전체 특성 수))만 고려합니다. 이로 인해 트리들이 서로 다른 관점에서 데이터를 바라보게 됩니다.

OOB(Out-of-Bag) 점수를 활용하면 별도의 검증 세트 없이도 모델 성능을 추정할 수 있습니다. 각 트리 학습에 사용되지 않은 샘플(약 37%)로 해당 트리를 평가하고, 이 점수들을 평균냅니다.

실습을 통해 랜덤포레스트가 의사결정나무보다 안정적이고 일반화 성능이 우수함을 확인했습니다. n_estimators는 100개 이상이면 대부분 충분하며, 특성 중요도 분석에서도 랜덤포레스트가 더 신뢰할 수 있는 결과를 제공합니다.

다음 16차시에서는 비지도학습인 클러스터링과 이상 탐지를 다룹니다. 레이블 없이 데이터의 패턴을 찾는 방법을 학습합니다. 수고하셨습니다.

## 16차시: 비지도학습 - 클러스터링과 이상탐지

### 강의 도입

안녕하세요. 이번 16차시에서는 비지도학습의 핵심인 클러스터링과 이상 탐지를 학습합니다.

지금까지 우리는 15차시까지 랜덤포레스트를 포함한 다양한 지도학습 모델을 다뤘습니다. 지도학습은 정답 레이블이 있어야 학습이 가능했습니다. "이 제품은 양품이다", "이 센서 값에서 불량이 발생했다"와 같은 정답이 필요했습니다. 하지만 실무에서는 레이블이 없거나 레이블을 확보하는 비용이 매우 큰 경우가 많습니다. 예를 들어, 신제품에 대한 분류 체계가 아직 없거나, 불량 사례 없이 정상 데이터만 축적된 상황이 있습니다.

이번 차시에서는 정답 없이 데이터의 패턴과 구조를 발견하는 비지도학습을 배웁니다. 비지도학습은 데이터 자체의 특성만으로 유사한 그룹을 찾거나, 정상 패턴에서 벗어난 이상치를 탐지하는 데 활용됩니다.

이번 차시에서 다룰 핵심 내용은 네 가지입니다. 첫째, 비지도학습의 개념과 활용 사례를 이해합니다. 고객 세분화, 이상 탐지, 차원 축소 등 다양한 적용 분야를 살펴봅니다. 둘째, K-Means 알고리즘으로 유사한 데이터를 군집화하는 방법을 실습합니다. K개의 중심점을 기준으로 데이터를 할당하고 중심을 업데이트하는 과정을 반복합니다. 셋째, 엘보우 방법과 실루엣 점수로 최적의 군집 개수(K)를 결정하는 방법을 학습합니다. 엘보우 방법은 Inertia 감소율이 급격히 줄어드는 지점을 찾고, 실루엣 점수는 군집의 응집도와 분리도를 종합적으로 평가합니다. 넷째, 군집 중심에서 거리가 먼 데이터를 이상치로 탐지하는 기법을 다룹니다.

제조 현장에서 설비 이상이나 품질 문제를 조기에 발견하는 데 활용할 수 있는 실용적인 내용입니다.

### 강의 마무리

이번 차시에서는 비지도학습의 핵심 기법인 클러스터링과 이상 탐지를 학습했습니다.

핵심 내용을 정리합니다. 첫째, 비지도학습은 레이블 없이 데이터의 패턴과 구조를 발견하는 방법입니다. 지도학습처럼 정답을 알려주지 않아도 데이터 자체의 특성에서 유의미한 정보를 추출합니다.

둘째, K-Means 알고리즘은 K개의 중심점을 기준으로 유사한 데이터를 군집화합니다. 작동 방식은 다음과 같습니다: 1) K개의 중심점을 랜덤 초기화, 2) 각 데이터를 가장 가까운 중심점에 할당, 3) 각 군집의 평균으로 중심점 업데이트, 4) 중심점이 변하지 않을 때까지 2-3 반복.

셋째, 최적의 군집 개수 K를 결정하는 두 가지 방법을 배웠습니다. 엘보우 방법은 K를 증가시키며 Inertia(군집 내 거리 합)를 계산하고, 감소율이 급격히 줄어드는 "팔꿈치" 지점을 선택합니다. 실루엣 점수는 군집의 응집도와 분리도를 종합적으로 평가하며, -1에서 1 사이 값으로 1에 가까울수록 좋은 군집입니다.

넷째, 클러스터링 기반 이상 탐지는 군집 중심에서 거리가 먼 데이터를 이상치로 판별합니다. 임계값 설정이 탐지 성능의 핵심입니다. 너무 낮으면 정상을 이상으로 오탐하고, 너무 높으면 실제 이상을 놓칩니다.

다음 17차시에서는 모델 평가와 반복 검증을 학습합니다. 교차 검증을 통해 모델의 일반화 성능을 체계적으로 평가하고, 과대적합과 과소적합을 진단하는 방법을 다룹니다. 수고하셨습니다.

## 17차시: 모델평가와 반복검증

### 강의 도입

안녕하세요. 이번 17차시에서는 모델 평가와 반복 검증에 대해 학습합니다.

지난 16차시에서 비지도학습을 통해 K-Means 클러스터링과 이상 탐지를 배웠습니다. 레이블 없이 데이터의 패턴을 발견하는 방법을 익혔습니다. 이제 지금까지 배운 다양한 모델 구축 방법을 토대로, 이렇게 만든 모델들이 실제로 얼마나 잘 작동하는지 체계적으로 평가하는 방법을 알아봅니다.

모델을 학습시켰다고 해서 바로 실무에 적용할 수 있는 것이 아닙니다. 학습 데이터에서만 잘 작동하고 새로운 데이터에서는 성능이 떨어지는 과대적합 문제가 발생할 수 있기 때문입니다. 단일 평가 결과만으로는 모델의 진정한 성능을 파악하기 어렵습니다. 체계적인 평가 체계를 갖추어야 신뢰할 수 있는 모델을 선정하고 실무에 적용할 수 있습니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 정밀도, 재현율, F1 점수 등 분류 모델의 핵심 평가 지표를 학습합니다. 정밀도는 예측한 양성 중 실제 양성 비율이고, 재현율은 실제 양성 중 예측 양성 비율입니다. F1 점수는 정밀도와 재현율의 조화 평균으로 불균형 데이터에서 특히 유용합니다. 둘째, ROC-AUC 곡선을 통해 다양한 임계값에서 모델 성능을 종합적으로 평가하는 방법을 익힙니다. 셋째, K-Fold 교차검증을 통해 단일 분할의 불안정성을 극복하고 모델 성능을 안정적으로 측정하는 방법을 실습합니다. 데이터를 K개로 나누어 순환 평가하므로 더 신뢰할 수 있는 성능 추정이 가능합니다. 넷째, 학습 곡선을 활용하여 과대적합과 과소적합을 진단하는 기법을 배웁니다.

모델 평가 능력은 좋은 모델을 선택하고 개선하는 데 필수적입니다. 함께 시작하겠습니다.

### 강의 마무리

이번 차시에서는 모델 평가와 반복 검증의 핵심 개념을 학습했습니다.

먼저 분류 모델의 핵심 평가 지표를 정리합니다. 정밀도(Precision)는 예측한 양성 중 실제 양성 비율이고, 재현율(Recall)은 실제 양성 중 예측 양성 비율입니다. F1 점수는 정밀도와 재현율의 조화 평균으로, 불균형 데이터에서 정확도보다 신뢰할 수 있는 지표입니다. 조화 평균을 사용하는 이유는 두 값 중 하나가 극단적으로 낮으면 F1 점수도 낮아지기 때문입니다.

ROC-AUC 곡선은 다양한 임계값에서 TPR(재현율)과 FPR(위양성률)의 관계를 보여줍니다. AUC(Area Under Curve)는 곡선 아래 면적으로, 1에 가까울수록 좋은 모델입니다. 0.5는 랜덤 추측 수준입니다.

K-Fold 교차검증을 통해 단일 분할의 불안정성을 극복하고 모델 성능을 신뢰성 있게 측정하는 방법을 익혔습니다. 데이터를 K개로 나누어 각 폴드를 한 번씩 검증 세트로 사용하고 나머지로 학습합니다. K개의 점수 평균과 표준편차로 모델의 일반화 성능을 추정합니다. 일반적으로 K=5 또는 K=10을 사용합니다.

학습 곡선과 검증 곡선을 활용하여 과대적합과 과소적합을 진단하는 기법도 다루었습니다. 학습 점수는 높은데 검증 점수가 낮으면 과대적합, 둘 다 낮으면 과소적합입니다.

다음 18차시에서는 모델 설정값 최적화를 학습합니다. GridSearchCV와 RandomizedSearchCV를 활용하여 하이퍼파라미터 튜닝을 자동화하는 방법을 다룹니다. 수고하셨습니다.

## 18차시: 모델설정값 최적화

### 강의 도입

안녕하세요. Part III 머신러닝 심화의 마지막 차시인 18차시 "모델 설정값 최적화"를 시작합니다.

지난 17차시에서는 교차검증과 다양한 평가 지표를 통해 모델 성능을 정확하게 측정하는 방법을 학습했습니다. K-Fold 교차검증으로 안정적인 성능 추정이 가능해졌고, 정밀도, 재현율, F1 점수로 모델을 다각도로 평가할 수 있게 되었습니다. 이번 차시에서는 한 단계 더 나아가, 측정된 성능을 체계적으로 높이는 하이퍼파라미터 튜닝 기법을 다룹니다.

하이퍼파라미터는 학습 전에 사람이 설정하는 값입니다. 의사결정나무의 max_depth, 랜덤포레스트의 n_estimators, 로지스틱 회귀의 C 값 등이 대표적입니다. 이 값들은 모델이 스스로 학습하지 않으므로 우리가 직접 최적의 조합을 찾아야 합니다. 최적의 하이퍼파라미터를 찾느냐에 따라 모델 성능이 크게 달라질 수 있습니다.

이번 강의에서는 세 가지 핵심 탐색 방법을 학습합니다. 첫째, Grid Search는 모든 조합을 철저하게 탐색합니다. 지정한 파라미터 값들의 모든 조합을 시도하므로 최적값을 놓치지 않지만, 조합이 많아지면 시간이 오래 걸립니다. 둘째, Random Search는 효율적인 랜덤 샘플링 기반의 탐색을 수행합니다. 전체를 탐색하지 않고도 좋은 조합을 빠르게 찾을 수 있어 넓은 탐색 공간에서 효과적입니다. 셋째, Bayesian Optimization은 이전 탐색 결과를 활용하여 다음 탐색 지점을 지능적으로 선택합니다. 탐색 효율이 가장 높지만 구현이 복잡합니다.

실무에서는 Random Search로 넓은 범위를 먼저 탐색한 후 Grid Search로 정밀 탐색하는 2단계 전략이 효과적입니다. 각 방법의 장단점을 이해하고, sklearn의 GridSearchCV와 RandomizedSearchCV를 활용한 실습을 진행합니다.

### 강의 마무리

이번 차시에서는 하이퍼파라미터 튜닝의 핵심 개념과 실무 적용 방법을 학습했습니다.

핵심 내용을 정리합니다. 첫째, 하이퍼파라미터는 학습 전에 사람이 설정하는 값으로 모델 성능에 큰 영향을 미칩니다. max_depth, n_estimators, learning_rate 등이 대표적입니다. 모델이 데이터에서 학습하는 가중치와 달리, 하이퍼파라미터는 우리가 직접 최적값을 찾아야 합니다.

둘째, GridSearchCV는 모든 조합을 탐색하여 철저하지만 시간이 많이 소요됩니다. 파라미터 3개, 각 5개 값이면 125번 학습이 필요합니다. 탐색 공간이 작을 때 적합합니다.

셋째, RandomizedSearchCV는 랜덤 샘플링으로 효율적인 탐색이 가능합니다. 지정한 횟수만큼만 탐색하므로 넓은 범위를 빠르게 훑을 수 있습니다. 연구에 따르면 60번의 랜덤 탐색으로 95% 확률로 상위 5% 조합을 찾을 수 있습니다.

넷째, 실무에서는 Random Search로 넓은 범위를 먼저 탐색한 후, 유망한 영역을 좁혀 Grid Search로 정밀 탐색하는 2단계 전략이 효과적입니다. Bayesian Optimization은 이전 결과를 활용해 지능적으로 다음 탐색 지점을 선택하여 효율이 가장 높습니다.

이것으로 Part III 머신러닝 심화 과정을 마무리합니다.

## 19차시: 시계열 데이터 분석과 예측

### 강의 도입

안녕하세요. Part IV 시계열과 딥러닝 파트가 시작됩니다.

지난 18차시까지 하이퍼파라미터 튜닝을 통해 일반적인 머신러닝 모델의 최적화 방법을 완성했습니다. GridSearchCV와 RandomizedSearchCV로 최적의 파라미터 조합을 찾는 방법을 익혔습니다. 이제 시간이라는 새로운 차원을 다루는 방법을 배웁니다.

시계열 데이터는 왜 특별한 처리가 필요할까요? 일반 데이터에서는 행을 무작위로 섞어도 정보가 손실되지 않습니다. 하지만 시계열 데이터는 시간 순서 자체가 중요한 정보입니다. 어제의 생산량이 오늘에 영향을 주고, 지난 여름의 패턴이 다음 여름에 반복됩니다. 제조 현장에서도 설비 센서 값의 변화 추이, 생산량의 계절적 변동, 품질 지표의 시간적 흐름을 분석해야 하는 상황이 많습니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 시계열의 핵심 구성요소인 추세(Trend)와 계절성(Seasonality)을 이해합니다. 데이터가 장기적으로 증가하거나 감소하는 추세, 주기적으로 반복되는 계절성 패턴을 분해하는 방법을 배웁니다. 둘째, Lag 특성과 이동평균(Rolling)을 활용한 특성 엔지니어링을 실습합니다. 과거 값을 특성으로 변환하여 미래를 예측하는 데이터를 준비합니다. 셋째, RandomForest로 실제 예측 모델을 만들어 MAE, RMSE, MAPE 지표로 평가해봅니다. 각 지표의 의미와 활용 상황을 이해합니다. 넷째, 시간 기준 분할과 TimeSeriesSplit 교차검증이 왜 필수인지 배웁니다. 시계열에서는 랜덤 분할이 아닌 시간 기준 분할을 사용해야 미래 정보 누출을 방지할 수 있습니다.

시계열 분석은 예측과 이상 탐지의 핵심 기술입니다. 함께 시작해 보겠습니다.

### 강의 마무리

이번 차시에서 시계열 데이터의 본질을 학습했습니다.

시계열은 추세(Trend), 계절성(Seasonality), 잔차(Residual)로 분해됩니다. 추세는 장기적인 증가 또는 감소 방향이고, 계절성은 주기적으로 반복되는 패턴입니다. 과거 값이 현재에 영향을 주는 자기상관 특성도 시계열의 핵심 특징입니다.

핵심 개념을 정리합니다. 첫째, Lag 특성과 Rolling 특성 생성 시 반드시 shift(1)을 먼저 적용해야 미래 정보 누출을 방지할 수 있습니다. shift(1)은 데이터를 한 시점 뒤로 밀어서 "어제 값"을 특성으로 사용하게 합니다. shift 없이 rolling을 적용하면 현재 값이 포함되어 미래 정보가 누출됩니다.

둘째, 시계열에서는 랜덤 분할이 아닌 시간 기준 분할이 필수입니다. 과거 데이터로 학습하고 미래 데이터로 평가해야 실제 예측 상황과 동일한 조건이 됩니다. K-Fold 대신 TimeSeriesSplit을 사용해야 시간 순서가 보존됩니다.

셋째, 회귀 평가 지표의 의미를 이해했습니다. MAE(평균 절대 오차)는 해석이 쉽고, RMSE(평균 제곱근 오차)는 큰 오차에 민감하며, MAPE(평균 절대 백분율 오차)는 상대적 오차를 백분율로 보여줍니다. 데이터 스케일에 따라 적절한 지표를 선택합니다.

다음 20차시에서는 딥러닝 입문으로 신경망 기초를 다룹니다. 시계열에서 배운 복잡한 패턴을 더 유연하게 학습할 수 있는 딥러닝의 세계로 진입합니다. 퍼셉트론부터 다층 신경망까지, 새로운 학습 패러다임이 기다리고 있습니다. 수고하셨습니다.

## 20차시: 딥러닝 입문 - 신경망 기초

### 강의 도입

안녕하세요. 이번 20차시에서는 딥러닝의 기초가 되는 신경망에 대해 학습합니다.

지금까지 의사결정나무, 랜덤포레스트, 로지스틱 회귀 등 다양한 머신러닝 모델을 다루었고, 19차시에서는 시계열 데이터의 특성과 예측 방법까지 경험했습니다. 이러한 기반 위에 이제 본격적으로 딥러닝의 세계로 진입합니다.

딥러닝은 기존 머신러닝과 어떤 점이 다를까요? 기존 머신러닝에서는 도메인 지식을 바탕으로 특성(feature)을 직접 설계해야 했습니다. 반면 딥러닝은 특성을 자동으로 추출하고, 여러 층을 쌓아 복잡한 패턴을 학습할 수 있습니다. 이미지 인식, 자연어 처리, 음성 인식 등 다양한 분야에서 혁신적인 성과를 이끌어낸 기술입니다. 제조 현장에서도 외관 검사, 설비 이상 탐지, 품질 예측 등에 딥러닝이 활발히 적용되고 있습니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 신경망의 기본 단위인 인공 뉴런의 구조를 이해합니다. 입력에 가중치를 곱하고 편향을 더한 후 활성화 함수를 적용하는 과정을 살펴봅니다. 둘째, 비선형성을 부여하는 활성화 함수를 학습합니다. Sigmoid, ReLU, Softmax 각각의 특성과 적용 상황을 배웁니다. 셋째, 여러 층으로 구성된 다층 퍼셉트론(MLP)의 구조를 살펴봅니다. 입력층, 은닉층, 출력층의 역할을 이해하고, 층이 깊어질수록 복잡한 패턴을 표현할 수 있음을 확인합니다. 넷째, 입력에서 출력으로 계산하는 순전파와 손실을 줄이기 위해 가중치를 조정하는 역전파 알고리즘의 원리를 이해합니다.

NumPy를 활용한 직접 구현을 통해 신경망 학습의 핵심 메커니즘을 체험해 보겠습니다.

### 강의 마무리

이번 차시에서는 딥러닝의 기초가 되는 신경망의 핵심 개념을 학습했습니다.

인공 뉴런은 입력에 가중치를 곱하고 편향을 더한 후 활성화 함수를 적용하여 출력을 생성합니다. 수식으로 표현하면 output = activation(Σ(입력 × 가중치) + 편향)입니다. 이 단순한 구조가 수천, 수만 개 연결되어 복잡한 패턴을 학습합니다.

활성화 함수는 비선형성을 부여하는 핵심 요소입니다. 은닉층에서는 ReLU(음수는 0, 양수는 그대로)를 주로 사용합니다. 이진 분류 출력층에서는 Sigmoid(0~1 사이 확률 출력), 다중 분류에서는 Softmax(각 클래스 확률 합이 1)를 사용합니다.

다층 퍼셉트론(MLP)은 입력층, 은닉층, 출력층으로 구성됩니다. 입력층은 데이터를 받아들이고, 은닉층은 특징을 추출하며, 출력층은 최종 예측을 출력합니다. 층이 깊어질수록 더 복잡한 패턴을 표현할 수 있지만, 과대적합 위험도 증가합니다.

신경망 학습은 순전파로 예측값을 계산하고, 손실 함수로 오차를 측정한 후, 역전파로 각 가중치의 기울기를 구하여 경사하강법으로 업데이트하는 과정을 반복합니다. 역전파는 출력층에서 입력층 방향으로 오차를 전파하며 각 가중치가 오차에 얼마나 기여했는지 계산합니다.

XOR 문제 실습을 통해 단일 퍼셉트론으로는 해결할 수 없는 비선형 문제를 은닉층이 있는 신경망이 해결할 수 있음을 확인했습니다.

다음 21차시에서는 Keras/TensorFlow를 활용하여 실제 제조 데이터에 MLP를 적용하고, Sequential 모델 구축과 학습 곡선 분석을 실습합니다. 수고하셨습니다.

## 21차시: 딥러닝 - 퍼셉트론에서 MLP까지

### 강의 도입

안녕하세요. 오늘부터 딥러닝의 세계로 본격적으로 들어갑니다.

지난 20차시에서는 인공 뉴런의 구조, 활성화 함수, 순전파와 역전파 등 신경망의 수학적 원리를 학습했습니다. NumPy로 간단한 신경망을 구현하며 핵심 메커니즘을 체험했습니다. 이론을 이해하는 것도 중요하지만, 실제로 모델을 구현하고 학습시켜 보아야 딥러닝의 진정한 힘을 체감할 수 있습니다.

딥러닝이라는 이름이 어렵게 느껴질 수 있지만, 그 시작은 매우 단순합니다. 바로 우리 뇌 속 신경세포, 뉴런을 흉내 내는 것에서 출발합니다. 1958년, 프랭크 로젠블랫이 퍼셉트론을 발명했을 때 사람들은 인공지능의 미래가 밝다고 생각했습니다. 하지만 퍼셉트론에는 치명적인 한계가 있었습니다. XOR이라는 간단한 문제조차 풀 수 없었던 것입니다. 선형으로 분리할 수 없는 문제 앞에서 퍼셉트론은 무력했습니다.

그러나 해결책은 의외로 간단했습니다. 층을 하나 더 쌓으면 됩니다. 이것이 바로 다층 퍼셉트론, MLP입니다. 은닉층이 공간을 변환하여 원래는 직선으로 나눌 수 없던 문제를 나눌 수 있게 만듭니다.

이번 차시에서는 Keras와 TensorFlow를 활용하여 다층 퍼셉트론(MLP) 모델을 직접 구현합니다. Sequential 모델로 신경망을 설계하고, Dense 층과 Dropout을 배치하여 품질 예측 분류기를 만들어 봅니다. 또한 Early Stopping으로 과적합을 방지하고, Batch Normalization으로 학습을 안정화하는 실전 기법을 익힙니다. 이론에서 배운 개념들이 코드로 어떻게 구현되는지 직접 확인해 보겠습니다.

### 강의 마무리

오늘 우리는 딥러닝의 핵심 원리를 처음부터 차근차근 살펴보았습니다.

생물학적 뉴런에서 영감을 받은 퍼셉트론이 AND와 OR 같은 문제는 해결할 수 있지만, XOR처럼 선형으로 분리할 수 없는 문제 앞에서는 무력했습니다. XOR 문제는 입력이 (0,0)과 (1,1)일 때 0, (0,1)과 (1,0)일 때 1을 출력해야 하는데, 직선 하나로는 두 그룹을 나눌 수 없습니다.

하지만 은닉층을 추가한 다층 퍼셉트론(MLP)이 이 한계를 극복했습니다. 은닉층이 입력 공간을 비선형 변환하여 원래는 직선으로 나눌 수 없던 문제를 나눌 수 있게 만든다는 점이 핵심입니다. 첫 번째 은닉층이 공간을 뒤틀고, 그 변환된 공간에서는 직선으로 분리가 가능해집니다.

순전파(Forward Propagation)는 입력에서 출력 방향으로 계산을 수행합니다. 역전파(Back Propagation)는 출력에서 발생한 오차의 원인을 추적하여 각 가중치를 수정하는 과정입니다. 연쇄 법칙(Chain Rule)을 활용하여 깊은 층까지 기울기를 전달합니다. 이 두 과정이 반복되면서 신경망이 점점 더 정확한 예측을 하게 됩니다.

복잡해 보이는 딥러닝도 결국 이 단순한 원리의 반복입니다. 층을 더 깊이 쌓고, 뉴런 수를 늘리며, 다양한 활성화 함수와 최적화 기법을 적용하는 것이 현대 딥러닝의 발전 방향입니다.

다음 시간에는 Keras를 사용하여 오늘 배운 개념을 실제 코드로 구현해보겠습니다. 수식과 이론이 어떻게 몇 줄의 코드로 변환되는지 직접 확인하실 수 있습니다. 수고하셨습니다.

## 22차시: 딥러닝 실습 - MLP 품질예측

### 강의 도입

안녕하세요. 이번 22차시에서는 MLP를 활용한 품질 예측 실습을 진행합니다.

지난 21차시에서는 퍼셉트론의 역사와 한계, 그리고 다층 퍼셉트론(MLP)이 이를 극복하는 원리를 학습했습니다. XOR 문제를 통해 은닉층이 공간을 변환하여 비선형 문제를 해결하는 메커니즘을 이해했습니다. 오늘은 지난 차시에서 배운 개념들을 실제 코드로 구현하며 체화합니다.

실습 환경으로는 Keras와 TensorFlow를 사용합니다. Keras는 직관적인 API를 제공하여 복잡한 신경망을 몇 줄의 코드로 구현할 수 있게 해줍니다. 딥러닝 입문자에게 최적화된 프레임워크입니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, Keras의 Sequential 모델로 신경망 구조를 설계합니다. Dense 층을 쌓아 입력층, 은닉층, 출력층을 구성하는 방법을 배웁니다. 둘째, compile 메서드로 옵티마이저, 손실 함수, 평가 지표를 설정하고, fit 메서드로 학습을 수행하는 흐름을 익힙니다. 셋째, 과적합 방지 기법을 실습합니다. Dropout은 학습 중 뉴런의 일부를 무작위로 비활성화하여 모델의 일반화 성능을 높이고, Early Stopping은 검증 손실이 개선되지 않을 때 학습을 자동으로 중단합니다. 넷째, Batch Normalization으로 각 층의 입력을 정규화하여 학습을 안정화하고 수렴 속도를 높이는 방법을 배웁니다.

제조 품질 데이터를 활용하여 양품/불량을 분류하는 MLP 모델을 직접 구현해 보겠습니다. 학습 곡선을 시각화하여 과적합 여부를 진단하는 방법도 함께 다룹니다. 이론이 실제 코드로 변환되는 과정을 체험해 보겠습니다.

### 강의 마무리

이번 차시에서는 Keras 프레임워크를 활용하여 MLP 모델을 구현하고 학습시키는 전체 과정을 실습했습니다.

Sequential 모델로 신경망 구조를 설계하는 방법을 배웠습니다. Dense 층을 순차적으로 쌓아 입력층, 은닉층, 출력층을 구성합니다. compile 메서드로 옵티마이저(Adam 등), 손실 함수(binary_crossentropy 등), 평가 지표(accuracy 등)를 설정합니다. fit 메서드로 학습을 수행하고, history 객체로 학습 과정을 기록합니다.

핵심 개념을 정리합니다. Dropout은 학습 중 뉴런의 일부를 무작위로 비활성화하여 과적합을 방지하고 모델의 일반화 성능을 높입니다. 보통 0.2~0.5 비율을 사용합니다. Early Stopping은 검증 손실(val_loss)이 patience 횟수 동안 개선되지 않으면 학습을 자동으로 중단합니다. restore_best_weights=True를 설정하면 최적의 가중치를 보존합니다.

Batch Normalization은 각 층의 입력을 정규화하여 학습을 안정화하고 수렴 속도를 높입니다. 내부 공변량 변화(Internal Covariate Shift)를 줄여주는 효과가 있습니다.

학습 곡선(Learning Curve)을 시각화하여 과적합 여부를 진단했습니다. 학습 손실은 계속 감소하는데 검증 손실이 증가하기 시작하면 과적합 신호입니다. 이 지점에서 Early Stopping이 학습을 중단합니다.

다음 23차시 딥러닝 응용: 오토인코더 기반 이상 탐지에서는 입력을 압축하고 복원하는 특수한 신경망 구조인 오토인코더를 학습합니다. 이를 통해 제조 현장의 비정상 패턴을 탐지하는 방법을 실습해 보겠습니다. 수고하셨습니다.

## 23차시: 딥러닝 - 오토인코더 이상탐지

### 강의 도입

안녕하세요. 23차시 강의를 시작합니다. 이번 차시에서는 딥러닝의 특수한 구조 중 하나인 오토인코더를 학습합니다.

지난 22차시에서는 Keras를 활용하여 MLP 모델을 직접 구현해 보았습니다. Sequential API와 Dense 레이어를 사용해 신경망을 구성하고, 역전파 알고리즘으로 가중치를 업데이트하는 원리를 학습했습니다. 또한 Dropout과 Early Stopping 같은 과적합 방지 기법도 실습했습니다. 이제 이 기반 위에서 새로운 신경망 구조를 배웁니다.

오토인코더는 인코더-디코더 구조를 가진 신경망입니다. 입력 데이터를 저차원의 잠재 공간(latent space)으로 압축하는 인코더와, 다시 원래 차원으로 복원하는 디코더로 구성됩니다. 특이한 점은 입력과 출력이 동일하다는 것입니다. 스스로를 재구성하도록 학습하는 과정에서 데이터의 핵심 특징을 압축된 표현으로 학습합니다.

이 구조가 이상 탐지에 왜 유용할까요? 정상 데이터만으로 학습한 오토인코더는 정상 패턴을 잘 복원합니다. 반면 비정상적인 데이터는 학습된 패턴과 다르기 때문에 복원 오차(재구성 오차)가 커집니다. 이 오차를 기준으로 이상 여부를 판정할 수 있습니다.

이번 차시에서는 오토인코더의 구조와 이상 탐지 원리를 학습합니다. 재구성 오차를 MSE로 계산하고, 임계값을 설정하여 이상을 판정하는 방법을 익힙니다. 실습에서는 UCI Machine Learning Repository의 AI4I 2020 Predictive Maintenance 데이터셋을 활용하여 설비 고장 탐지를 수행합니다. 레이블이 부족한 상황에서 비지도학습 기반으로 이상을 탐지하는 실무 기법을 체험해 보겠습니다.

### 강의 마무리

이번 차시에서는 오토인코더의 구조와 이상 탐지 원리를 학습했습니다.

오토인코더는 인코더가 입력을 잠재 공간으로 압축하고, 디코더가 이를 다시 복원하는 구조입니다. 입력과 출력이 동일하도록 학습하는 것이 특징입니다. 핵심은 정상 데이터만으로 학습하여 정상 패턴을 기억하게 하고, 새로운 데이터의 재구성 오차를 통해 이상 여부를 판정하는 것입니다.

주요 개념을 정리합니다. 재구성 오차(Reconstruction Error)는 원본과 복원된 데이터 간의 MSE(평균 제곱 오차)로 계산합니다. 정상 데이터는 잘 복원되어 오차가 작고, 비정상 데이터는 학습된 패턴과 달라 오차가 큽니다.

임계값(Threshold)은 정상 데이터의 재구성 오차 분포를 기반으로 설정합니다. 일반적으로 평균 + 2~3배 표준편차를 사용합니다. 오차가 임계값을 초과하면 이상으로 판정합니다. 임계값이 너무 낮으면 정상을 이상으로 오탐(False Positive)하고, 너무 높으면 실제 이상을 놓칩니다(False Negative).

Keras에서는 Sequential 또는 Functional API로 구현합니다. fit 함수에서 X를 입력(x)과 타겟(y) 모두에 사용하는 것이 특징입니다: model.fit(X_train, X_train). 이는 "자기 자신을 복원하라"는 학습 목표를 나타냅니다.

오토인코더의 장점은 정상 데이터만으로 학습할 수 있어 불량 사례가 부족한 상황에서 유용하다는 것입니다.

다음 24차시에서는 CNN 기반 이미지 불량 검출을 다룹니다. 합성곱 신경망을 활용하여 제조 현장의 이미지 데이터에서 불량을 탐지하는 방법을 학습합니다. 수고하셨습니다.

## 24차시: 딥러닝 CNN - 이미지 불량검출

### 강의 도입

안녕하세요. Part IV 딥러닝의 마지막 이미지 처리 차시입니다.

지난 23차시에서는 오토인코더를 통해 비지도학습 기반의 차원 축소와 이상 탐지를 배웠습니다. 인코더-디코더 구조를 이해하고, 재구성 오차를 활용한 비정상 데이터 검출 방법을 실습했습니다. 이번 차시에서는 이미지 데이터를 다루는 특별한 신경망인 합성곱 신경망(CNN, Convolutional Neural Network)을 학습합니다.

CNN은 왜 이미지 처리에 적합할까요? 일반적인 MLP(다층 퍼셉트론)는 이미지를 1차원 벡터로 펼쳐서 입력합니다. 이 과정에서 픽셀 간의 공간적 관계가 무시됩니다. 반면 CNN은 이미지의 2차원 구조를 그대로 유지하면서 학습합니다. 합성곱 연산을 통해 에지, 텍스처, 형태 등 계층적 특징을 자동으로 추출합니다. 이러한 특성 덕분에 제품 외관 검사에 매우 적합합니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, 합성곱 연산의 수학적 정의와 다채널 확장을 이해합니다. 필터(커널)가 이미지를 훑으며 특성 맵을 생성하는 과정을 살펴봅니다. 둘째, 특성 맵 크기 계산 공식을 학습합니다. 입력 크기, 필터 크기, 스트라이드, 패딩에 따라 출력 크기가 어떻게 결정되는지 계산합니다. 셋째, Keras의 Conv2D, MaxPooling2D, Flatten 층을 활용하여 CNN 모델을 구성하는 방법을 배웁니다. 넷째, Kaggle의 Casting Product Image 데이터셋을 활용하여 주조 제품의 결함을 검출하는 실습을 진행합니다.

이미지 전처리의 효과를 비교하고, 혼동 행렬과 Recall 분석을 통해 제조업 관점의 성능 평가 방법도 함께 배웁니다.

### 강의 마무리

이번 차시에서는 CNN 기반 이미지 불량 검출을 학습했습니다.

합성곱 연산의 수학적 정의와 다채널 확장 수식을 이해했습니다. 필터(커널)가 이미지를 훑으며 특성 맵을 생성합니다. 초기 층에서는 에지와 같은 저수준 특징을, 깊은 층에서는 형태와 같은 고수준 특징을 추출합니다. 특성 맵 크기 계산 공식: 출력 크기 = (입력 크기 - 필터 크기 + 2×패딩) / 스트라이드 + 1.

Keras의 핵심 층을 활용했습니다. Conv2D는 합성곱 연산을 수행하고, MaxPooling2D는 공간 크기를 줄이면서 중요한 특징을 유지합니다. Flatten은 2D 특성 맵을 1D 벡터로 펼쳐 Dense 층에 연결합니다.

Casting Product Image 데이터셋으로 주조 제품 결함 검출 실습을 진행했습니다. 이미지 전처리의 효과를 확인했습니다. 정규화(0~255 → 0~1 범위)는 학습 안정성을 높이고, 리사이즈는 일관된 입력 크기를 보장합니다.

혼동 행렬과 Recall 분석을 통해 제조업 관점의 성능 평가 방법을 배웠습니다. 제조업에서는 불량을 정상으로 오판하는 것(False Negative)이 치명적이므로 Recall(재현율)이 특히 중요합니다. 불량 하나를 놓치면 고객에게 전달되어 큰 손실을 야기할 수 있기 때문입니다.

CNN은 이미지 데이터의 공간적 패턴을 학습하는 데 최적화된 구조입니다. 다음 차시에서는 시간적 패턴을 학습하는 순환신경망(RNN)을 다룹니다. 25차시에서는 RNN의 순환 구조, 기울기 소실 문제, LSTM과 GRU를 배웁니다. 수고하셨습니다.

## 25차시: 딥러닝 시계열 예측 - RNN과 LSTM

### 강의 도입

안녕하세요. 이번 25차시에서는 시계열 데이터 처리에 특화된 순환 신경망(RNN)과 LSTM을 학습합니다.

지난 24차시에서는 CNN을 활용한 이미지 기반 불량 검출을 학습했습니다. CNN은 합성곱 연산으로 이미지의 공간적 특징을 추출하여 제품 외관 결함을 검출하는 데 탁월한 성능을 보여주었습니다. CNN이 이미지의 공간적 패턴을 인식한다면, 이번 차시에서 배울 RNN은 시간적 순서와 패턴을 기억하는 데 특화된 구조입니다.

왜 시계열에는 특별한 신경망이 필요할까요? MLP나 CNN은 입력을 독립적으로 처리합니다. 하지만 시계열 데이터에서는 과거 값이 현재에 영향을 미칩니다. "어제 온도가 높았으니 오늘도 높을 가능성이 있다", "지난주 생산량 추세를 보면 이번 주도 비슷할 것이다"와 같은 시간적 의존성을 포착해야 합니다. RNN은 이전 시점의 정보를 은닉 상태(hidden state)로 전달하여 순차적 패턴을 학습합니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, RNN의 순환 구조를 이해합니다. 출력이 다시 입력으로 피드백되는 구조가 시퀀스 정보를 유지하는 원리를 살펴봅니다. 둘째, 기울기 소실(vanishing gradient) 문제를 확인합니다. 긴 시퀀스에서 역전파 시 기울기가 점점 작아져 학습이 어려워지는 현상입니다. 셋째, LSTM의 게이트 메커니즘을 학습합니다. Forget Gate, Input Gate, Output Gate가 어떻게 장기 의존성 문제를 해결하는지 이해합니다. 간소화된 GRU와의 차이점도 비교합니다. 넷째, Predictive Maintenance AI4I 2020 데이터셋을 활용하여 제조 설비의 센서값을 예측하는 실습을 진행합니다.

Sliding Window 기반 시퀀스 데이터 준비부터 Keras LSTM 모델 구현까지 시계열 예측의 전체 과정을 체험합니다.

### 강의 마무리

이번 차시에서는 시계열 데이터 처리를 위한 RNN과 LSTM을 학습했습니다.

RNN의 순환 구조가 이전 시점의 정보를 은닉 상태(hidden state)로 전달하는 방식을 이해했습니다. 현재 시점의 출력은 현재 입력과 이전 은닉 상태의 조합으로 결정됩니다. 이 구조 덕분에 시퀀스의 순차적 패턴을 학습할 수 있습니다. 그러나 긴 시퀀스에서는 역전파 시 기울기가 점점 작아지는 기울기 소실(Vanishing Gradient) 문제가 발생하여 먼 과거의 정보를 학습하기 어렵습니다.

LSTM(Long Short-Term Memory)의 3가지 게이트가 이 문제를 해결합니다. Forget Gate는 이전 정보 중 버릴 것을 결정합니다. Input Gate는 새로운 정보 중 저장할 것을 결정합니다. Output Gate는 셀 상태에서 출력할 것을 결정합니다. 셀 상태(Cell State)가 정보를 장기간 유지하는 고속도로 역할을 하여 장기 의존성 문제를 해결합니다.

GRU(Gated Recurrent Unit)는 LSTM을 간소화한 버전입니다. Reset Gate와 Update Gate 두 개만 사용하여 파라미터가 적고 학습이 빠릅니다. 성능은 LSTM과 비슷한 경우가 많습니다.

Predictive Maintenance AI4I 2020 데이터로 실습을 진행했습니다. Sliding Window 기반 시퀀스 데이터 준비 방법을 배웠습니다. 예를 들어 window_size=10이면 과거 10개 시점 데이터로 다음 시점을 예측합니다. Keras LSTM 층을 활용하여 센서값 예측 모델을 구현했습니다.

다음 26차시에서는 딥러닝 모델 해석과 파인튜닝을 다룹니다. 학습된 모델이 어떤 근거로 예측을 수행하는지 분석하고, 모델 성능을 최적화하는 기법을 학습합니다. 수고하셨습니다.

## 26차시: 모델 해석과 파인튜닝 실무전략

### 강의 도입

안녕하세요. 이번 26차시에서는 모델 해석과 파인튜닝, 그리고 실무에서 필요한 다양한 기술을 학습합니다.

지난 25차시에서 RNN과 LSTM으로 시계열 데이터를 다루는 방법을 배웠습니다. 순환 구조로 시간적 패턴을 학습하고, 게이트 메커니즘으로 장기 의존성 문제를 해결하는 원리를 이해했습니다. 이제 모델을 만들 줄 알게 되었으니, 한 단계 더 나아가 볼 차례입니다.

모델을 만드는 것만으로는 충분하지 않습니다. 실무에서는 "왜 이렇게 판단했는가?"라는 질문에 답해야 합니다. 특히 제조 현장에서 품질 문제가 발생했을 때, 모델이 어떤 근거로 불량을 예측했는지 설명할 수 있어야 합니다. 또한 학습 과정을 체계적으로 추적하고, 최적의 모델을 저장하며, 적은 데이터로도 좋은 성능을 내는 전략이 필요합니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, Grad-CAM으로 CNN의 판단 근거를 시각화합니다. 이미지의 어느 영역을 보고 불량이라고 판단했는지 히트맵으로 확인할 수 있습니다. 둘째, TensorBoard와 Callbacks로 학습을 체계적으로 관리합니다. 손실 함수와 정확도의 변화를 실시간으로 모니터링하고, EarlyStopping으로 과적합을 방지하며, ModelCheckpoint로 최고 성능 모델을 자동 저장합니다. 셋째, joblib과 Pipeline을 활용하여 모델을 저장하고 재활용하는 방법을 배웁니다. 전처리와 모델을 하나의 객체로 관리하면 배포가 간편해집니다. 넷째, 전이학습(Transfer Learning)과 파인튜닝(Fine-tuning)을 학습합니다. ImageNet 등에서 사전학습된 모델을 활용하여 적은 데이터로도 높은 성능을 달성하는 핵심 기법입니다.

모델을 만드는 것에서 끝나지 않고, 실무에서 활용하기 위한 핵심 기술들을 함께 익혀 보겠습니다.

### 강의 마무리

이번 차시에서는 모델 해석부터 저장, 재활용까지 실무에 필요한 핵심 기술을 학습했습니다.

Grad-CAM으로 CNN이 어느 영역을 보고 판단했는지 시각화하는 방법을 익혔습니다. 마지막 합성곱 층의 기울기를 활용하여 입력 이미지 위에 히트맵을 생성합니다. 제조 현장에서 "왜 불량으로 판정했는가?"라는 질문에 시각적으로 답할 수 있어 의사결정의 투명성을 높입니다.

TensorBoard와 Callbacks로 학습 과정을 체계적으로 추적하는 방법을 다루었습니다. TensorBoard는 손실, 정확도, 학습률 등을 실시간으로 시각화합니다. EarlyStopping은 검증 손실이 개선되지 않으면 학습을 중단하여 과적합을 방지합니다. ModelCheckpoint는 최고 성능 모델을 자동으로 저장하여 최적의 가중치를 보존합니다.

joblib과 Pipeline을 활용하면 전처리와 모델을 하나의 객체로 관리할 수 있어 배포가 간편해집니다. joblib.dump()로 저장하고 joblib.load()로 불러옵니다. 새로운 데이터에 동일한 전처리를 적용하고 예측하는 과정이 한 줄로 가능합니다.

전이학습(Transfer Learning)과 파인튜닝(Fine-tuning)은 적은 데이터로도 높은 성능을 달성하는 핵심 기법입니다. ImageNet 등에서 사전학습된 모델(VGG, ResNet 등)의 특징 추출 능력을 활용합니다. 전이학습은 사전학습 층을 동결하고 마지막 층만 학습합니다. 파인튜닝은 일부 층을 동결 해제하여 새로운 데이터에 맞게 미세 조정합니다.

다음 27차시에서는 Streamlit과 FastAPI를 활용하여 학습된 모델을 실제 서비스로 배포하는 방법을 학습합니다. 전체 과정의 대미를 장식하겠습니다. 수고하셨습니다.

## 27차시: ML 모델 서비스 배포

### 강의 도입

안녕하세요. 전체 과정의 마지막 차시인 27차시 "ML 모델 서비스 배포"를 시작합니다.

지난 26차시에서 학습된 모델을 joblib과 pickle로 저장하고, Grad-CAM으로 모델을 해석하며, 전이학습과 파인튜닝으로 성능을 높이는 방법을 익혔습니다. 이제 저장된 모델을 실제 서비스로 배포하여 현장에서 활용할 수 있게 만드는 마지막 단계를 학습합니다.

모델이 아무리 뛰어나도 현장에서 활용할 수 없다면 의미가 없습니다. 품질 담당자가 웹 인터페이스에서 데이터를 입력하고 예측 결과를 확인할 수 있어야 하고, MES(Manufacturing Execution System) 같은 시스템이 자동으로 모델을 호출하여 실시간 예측을 수행할 수 있어야 합니다. 이것이 바로 모델 배포입니다.

이번 차시에서는 네 가지 핵심 내용을 다룹니다. 첫째, REST API의 기본 개념과 HTTP 통신 방식을 이해합니다. GET, POST, PUT, DELETE 메서드와 상태 코드의 의미를 배우고, requests 라이브러리로 API 호출을 실습합니다. 둘째, Streamlit으로 품질 담당자가 직접 사용할 수 있는 웹앱을 구축합니다. 몇 줄의 Python 코드만으로 인터랙티브한 대시보드를 만들 수 있습니다. 셋째, FastAPI로 MES 시스템이 자동 호출하는 API 엔드포인트를 구현합니다. Pydantic을 통한 데이터 검증과 자동 문서화 기능을 활용합니다. 넷째, Docker 컨테이너를 활용한 배포 기초를 다룹니다.

27차시 전체 과정의 마무리로, 데이터 수집부터 전처리, 모델 학습, 평가, 그리고 서비스 배포까지 완전한 ML 파이프라인을 완성해보겠습니다. 지금까지 배운 모든 내용이 하나로 연결되는 시간입니다.

### 강의 마무리

이번 차시에서는 REST API 기초부터 ML 모델 서비스 배포까지 학습했습니다.

HTTP 메서드(GET, POST, PUT, DELETE)와 상태 코드(200 성공, 404 Not Found, 500 서버 오류 등)의 의미를 이해했습니다. requests 라이브러리를 활용한 API 호출을 실습하여 외부 서비스와 통신하는 방법을 배웠습니다.

Streamlit으로 사용자가 직접 조작하는 웹앱을 구축했습니다. st.title(), st.slider(), st.button() 등 직관적인 함수로 인터랙티브한 대시보드를 만들 수 있습니다. 품질 담당자가 파라미터를 입력하고 예측 결과를 확인하는 인터페이스를 구현했습니다.

FastAPI로 외부 시스템이 호출하는 API 엔드포인트를 구현했습니다. @app.post() 데코레이터로 엔드포인트를 정의하고, Pydantic 모델로 입력 데이터를 검증합니다. 자동 문서화(/docs) 기능으로 API 테스트가 편리합니다. MES 시스템이 자동으로 호출하여 실시간 예측을 수행할 수 있습니다.

Docker 컨테이너 배포 기초도 다루었습니다. Dockerfile 작성, 이미지 빌드, 컨테이너 실행의 흐름을 이해했습니다. 컨테이너를 활용하면 어느 환경에서든 동일하게 동작하는 배포가 가능합니다.

27차시에 걸친 전체 과정을 통해 데이터 수집부터 전처리, 탐색적 분석, 머신러닝 모델 학습, 딥러닝, 모델 해석, 그리고 서비스 배포까지 데이터 분석의 전 과정을 완성했습니다. Python과 Pandas로 시작하여 scikit-learn, TensorFlow, Streamlit, FastAPI까지 실무에서 활용되는 핵심 도구들을 모두 경험했습니다.
