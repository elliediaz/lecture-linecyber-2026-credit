# 5차시 마무리

이번 차시에서는 기초 기술통계량과 탐색적 시각화의 핵심 개념을 학습했습니다.

먼저 대표값으로 평균, 중앙값, 최빈값을 배웠습니다. 평균은 모든 값을 반영하지만 이상치에 민감합니다. 중앙값은 이상치에 강건하여 데이터의 중심을 안정적으로 나타냅니다. 평균과 중앙값의 차이가 크면 데이터가 한쪽으로 치우쳐 있다는 신호입니다. 최빈값은 가장 자주 나타나는 값으로 범주형 데이터 분석에 유용합니다.

산포도 지표인 범위, 분산, 표준편차, IQR을 통해 데이터가 얼마나 흩어져 있는지 측정하는 방법도 익혔습니다. 표준편차가 작으면 데이터가 평균 주위에 모여 있고, 크면 넓게 퍼져 있습니다. IQR(사분위 범위)은 1사분위수와 3사분위수의 차이로, 이상치에 덜 민감한 산포 측정 방법입니다.

시각화에서는 히스토그램으로 분포 형태를, 상자그림(박스플롯)으로 사분위수와 이상치를, 산점도로 두 변수 간의 관계를 파악하는 방법을 실습했습니다. matplotlib과 seaborn 라이브러리를 활용하여 다양한 그래프를 그리는 방법을 배웠습니다. Pandas의 describe() 함수 하나로 주요 통계량을 한눈에 확인할 수 있다는 점도 기억해 주시기 바랍니다.

다음 6차시 '확률분포와 품질검정'에서는 정규분포와 Z-score, 그리고 통계적 검정의 기초를 학습합니다. 오늘 배운 기술통계량을 바탕으로 데이터 분석의 깊이를 한층 더해 나가겠습니다. 수고하셨습니다.
