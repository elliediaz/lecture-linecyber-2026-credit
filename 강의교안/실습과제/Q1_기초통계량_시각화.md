### 문제 5: 그룹별 통계량 비교 (30점)

**Machine failure** (불량 여부)별로 온도 평균을 비교하세요.

**수행 내용**:
1. 불량 여부별 데이터 건수 확인
2. 불량 여부별 온도 평균 계산
3. 막대 그래프로 시각화

**참고 코드**:
```python
# 불량 여부별 건수
print(df['Machine failure'].value_counts())

# 불량 여부별 평균 온도
group_mean = df.groupby('Machine failure')['Air temperature [K]'].mean()
print(group_mean)

# 막대 그래프
group_mean.plot(kind='bar', color=['green', 'red'], edgecolor='black')
plt.xlabel('Machine Failure (0: Normal, 1: Failure)')
plt.ylabel('Average Air Temperature (K)')
plt.title('Average Temperature by Machine Failure')
plt.xticks(rotation=0)
plt.show()
```

**작성할 내용**:
- 정상 제품과 불량 제품의 평균 온도 차이는 몇 K인가요?
- 이 차이가 의미하는 바는 무엇인가요?
- 온도가 불량 발생에 영향을 미칠 가능성이 있나요?
