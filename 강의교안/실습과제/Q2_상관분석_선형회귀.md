### 문제 1: 상관계수 계산 (20점)

공정 온도와 회전 속도의 **피어슨 상관계수**를 계산하세요.

**수행 내용**:
1. 두 변수 선택: `Process temperature [K]`, `Rotational speed [rpm]`
2. `df.corr()` 또는 개별 계산으로 상관계수 확인

**참고 코드**:
```python
# 방법 1: 전체 상관행렬
print(df.corr())

corr_value = df['Process temperature [K]'].corr(df['Rotational speed [rpm]'])
```

### 문제 3: 선형회귀 모델 학습 (25점)

sklearn의 **LinearRegression**을 사용하여 예측 모델을 만드세요.

**수행 내용**:
1. 특성(X)과 타겟(y) 분리
2. 모델 생성 및 학습
3. 회귀계수(기울기)와 절편 확인

**참고 코드**:
```python
from sklearn.linear_model import LinearRegression

# 특성(X)과 타겟(y) 정의
X = df[['Process temperature [K]']]  # 2차원 배열 형태 필요
y = df['Rotational speed [rpm]']

# 모델 생성 및 학습
model = LinearRegression()
model.fit(X, y)

# 회귀계수와 절편 출력
print(f"회귀계수 (기울기): {model.coef_[0]:.4f}")
print(f"절편: {model.intercept_:.4f}")
```

**작성할 내용**:
- 회귀식을 완성하세요: `회전속도 = ___ × 온도 + ___`
- 기울기가 양수/음수인 것은 무엇을 의미하나요?
- 온도가 1K 증가하면 회전 속도는 얼마나 변화하나요?

---

### 문제 4: 산점도에 회귀선 추가 (15점)

산점도 위에 회귀선을 그려서 모델의 적합도를 시각적으로 확인하세요.

**수행 내용**:
```python
# 예측값 계산
y_pred = model.predict(X)

# 시각화
plt.figure(figsize=(10, 6))
plt.scatter(df['Process temperature [K]'], y, alpha=0.5, label='Actual')
plt.plot(df['Process temperature [K]'], y_pred, color='red', linewidth=2, label='Regression Line')
plt.xlabel('Process Temperature (K)')
plt.ylabel('Rotational Speed (rpm)')
plt.title('Linear Regression: Temperature vs Rotational Speed')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

**작성할 내용**:
- 회귀선이 데이터의 경향을 잘 나타내고 있나요?
- 회귀선 주변에 데이터가 밀집되어 있나요, 아니면 넓게 퍼져 있나요?

### 문제 5: 모델 평가 및 예측 (20점)

**R² 점수**로 모델의 적합도를 평가하고, 새로운 값을 예측하세요.

**수행 내용**:
1. R² 점수 계산
2. 새로운 온도값에 대한 회전 속도 예측

**참고 코드**:
```python
from sklearn.metrics import r2_score

# R² 점수 계산
r2 = r2_score(y, y_pred)
print(f"R² Score: {r2:.4f}")

# 또는 model.score() 사용
print(f"R² Score: {model.score(X, y):.4f}")

# 새로운 값 예측
new_temp = [[310.0]]  # 310K
predicted_speed = model.predict(new_temp)
print(f"310K에서의 예측 회전속도: {predicted_speed[0]:.2f} rpm")
```

**작성할 내용**:
- R² 점수는 얼마인가요?
- 이 점수가 의미하는 바는 무엇인가요? (R²=1이면 완벽한 적합, R²=0이면 전혀 설명 못함)
- 이 모델을 실무에서 사용하기에 적합한가요? 그 이유는?
