# 3차시: 제조 데이터 다루기 기초

안녕하세요. 이번 3차시에서는 제조 데이터 분석의 핵심 도구인 NumPy와 Pandas를 학습합니다.

지난 2차시에서 Python 기초 문법을 익혔다면, 이제 그 기반 위에 데이터 분석 라이브러리를 활용하는 방법을 배웁니다. NumPy는 빠른 수치 계산과 배열 연산을 가능하게 하고, Pandas는 엑셀처럼 표 형태의 데이터를 효율적으로 다룰 수 있게 해줍니다. 이 두 라이브러리는 제조 현장의 센서 데이터 분석, 생산량 집계, 불량률 계산 등 실무 업무에서 필수적으로 사용됩니다.

오늘 배울 내용은 NumPy 배열의 생성과 연산, Pandas DataFrame의 구조와 활용, 그리고 CSV 파일을 불러와 데이터를 탐색하는 방법입니다. Python 기본 리스트로 5줄 걸리던 평균 계산이 NumPy로는 단 1줄로 가능해집니다. 이러한 효율성이 왜 데이터 분석에서 NumPy와 Pandas가 표준 도구로 자리잡았는지를 직접 체험하게 됩니다.
