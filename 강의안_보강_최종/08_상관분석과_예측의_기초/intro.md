# 8차시: 상관분석과 예측의 기초 - 도입

안녕하세요. 이번 차시에서는 두 변수 간의 관계를 분석하고 예측하는 방법을 학습합니다.

지난 7차시에서 t-검정과 ANOVA를 통해 그룹 간 차이가 통계적으로 유의미한지 검정하는 방법을 배웠습니다. 이제 한 단계 더 나아가, 변수들이 서로 어떤 관계를 맺고 있는지 분석해 보겠습니다.

이번 차시에서는 피어슨 상관계수를 통해 두 변수의 관계 강도와 방향을 수치로 표현하는 방법을 알아봅니다. 상관행렬과 히트맵으로 여러 변수 간 관계를 한눈에 파악하는 기법도 실습합니다. 또한 단순선형회귀의 원리를 이해하고, sklearn을 활용하여 실제 예측 모델을 구현해 봅니다. R-squared(결정계수)를 통해 모델의 설명력을 평가하는 방법도 함께 다룹니다.

상관분석과 회귀분석은 머신러닝 예측 모델의 기초가 되는 핵심 개념입니다. 이 차시를 통해 데이터 기반 예측의 첫걸음을 내딛어 보겠습니다.
