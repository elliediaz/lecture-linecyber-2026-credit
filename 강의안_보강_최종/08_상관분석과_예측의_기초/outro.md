# 8차시: 상관분석과 예측의 기초 - 마무리

수고하셨습니다. 이번 차시에서는 변수 간 관계를 분석하고 예측하는 핵심 기법들을 학습했습니다.

먼저 피어슨 상관계수를 통해 두 변수의 선형 관계를 -1에서 +1 사이의 값으로 측정하는 방법을 배웠습니다. 상관행렬과 히트맵을 활용하여 여러 변수 간 관계를 시각적으로 파악하는 실습도 진행했습니다. 단순선형회귀에서는 최소제곱법의 원리를 이해하고, sklearn의 LinearRegression으로 예측 모델을 직접 구현해 보았습니다. R-squared를 통해 모델이 데이터를 얼마나 잘 설명하는지 평가하는 방법도 익혔습니다.

핵심 포인트를 정리하면 다음과 같습니다. 상관계수의 절댓값이 0.7 이상이면 강한 상관관계로 해석합니다. 상관관계가 인과관계를 의미하지는 않으므로 도메인 지식과 함께 해석해야 합니다. sklearn 사용 시 X는 반드시 2D 배열로 변환해야 합니다.

다음 9차시 "제조 데이터 전처리 (1)"에서는 결측치와 이상치를 처리하는 방법을 배웁니다. 데이터 품질을 높여 예측 모델의 정확도를 향상시키는 실무 기법을 함께 익혀 보겠습니다.
