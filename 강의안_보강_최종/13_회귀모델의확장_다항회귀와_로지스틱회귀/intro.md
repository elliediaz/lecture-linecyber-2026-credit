# 13차시 강의 시작

안녕하세요. 이번 13차시에서는 회귀 모델의 확장에 대해 학습합니다.

지난 12차시에서 머신러닝의 기본 개념과 문제 유형에 대해 알아보았습니다. 이제 그 기초 위에서 실제 모델을 구현해 보겠습니다.

현실의 데이터는 단순한 직선 관계만 있는 것이 아닙니다. 온도가 높아질수록 불량률이 가속적으로 증가하거나, 변수들 간에 곡선 형태의 관계가 나타나는 경우가 많습니다. 이러한 비선형 관계를 다루기 위해 선형회귀를 확장한 다항회귀(Polynomial Regression)를 배웁니다. PolynomialFeatures를 활용하여 특성을 변환하고, 적절한 차수를 선택하는 방법을 실습합니다.

또한 "얼마나?"가 아닌 "무엇인가?"를 예측하는 분류 문제를 다룹니다. 시그모이드 함수를 통해 출력을 확률로 변환하는 로지스틱 회귀(Logistic Regression)를 학습하고, 제조 품질 분류 모델을 직접 구현해 보겠습니다.
