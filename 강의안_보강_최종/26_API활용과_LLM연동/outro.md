# 26차시: API 활용과 LLM 연동 - 마무리

이번 차시에서는 API의 기본 개념부터 LLM 활용까지 폭넓게 학습했습니다.

먼저 REST API의 구조와 HTTP 메서드(GET, POST)를 이해하고, requests 라이브러리로 외부 API를 호출하는 방법을 익혔습니다. JSON 데이터 형식의 직렬화와 역직렬화, 그리고 안전한 에러 처리 패턴도 함께 다루었습니다. 이어서 OpenAI와 Claude API의 호출 구조를 살펴보고, 메시지 역할(system, user, assistant)과 temperature 같은 주요 파라미터의 역할을 학습했습니다. 마지막으로 프롬프트 엔지니어링의 핵심 원칙인 역할 지정, 맥락 제공, 형식 지정 기법을 활용하여 제조업 데이터 분석에 LLM을 적용하는 방법을 실습했습니다.

다음 27차시 "ML 모델 서비스 배포"에서는 오늘 학습한 API 개념을 바탕으로, 실제 ML 모델을 프로덕션 환경에 배포하는 방법을 학습합니다.
