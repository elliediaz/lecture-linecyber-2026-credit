# 26차시: API 활용과 LLM 연동 - 도입

안녕하세요. 이번 26차시에서는 API 활용과 LLM 연동에 대해 학습합니다.

지난 25차시에서 학습한 모델 저장이 완료되었다면, 이제 이 모델을 실제 서비스로 만들어야 합니다. 여기서 핵심이 되는 기술이 바로 API입니다. API는 프로그램 간 통신을 가능하게 하는 규약으로, 저장된 ML 모델을 외부에서 호출할 수 있도록 서비스화하는 데 필수적인 기술입니다.

이번 차시에서는 REST API의 기본 개념과 HTTP 메서드, requests 라이브러리를 활용한 API 호출 방법을 학습합니다. 나아가 GPT, Claude와 같은 LLM API를 호출하는 방법과 프롬프트 엔지니어링 기법을 익혀, 제조 데이터 분석에 LLM을 활용하는 방법까지 다루게 됩니다. API 통신의 원리를 이해하면, 향후 여러분이 만든 모델을 웹 서비스로 배포하는 기반을 갖추게 됩니다.
