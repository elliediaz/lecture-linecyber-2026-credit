# 22차시: 딥러닝 응용 - 오토인코더 기반 이상 탐지

안녕하세요. 22차시 강의를 시작합니다.

지난 21차시에서는 Keras를 활용하여 MLP 모델을 직접 구현해 보았습니다. Sequential API와 Dense 레이어를 사용해 신경망을 구성하고, 품질 예측 문제에 적용하는 실습을 진행했습니다. 이번 차시에서는 그 경험을 바탕으로, 딥러닝의 특수한 구조 중 하나인 오토인코더를 학습합니다.

오토인코더는 인코더-디코더 구조를 가진 신경망으로, 입력 데이터를 저차원의 잠재 공간으로 압축한 뒤 다시 원래 차원으로 복원합니다. 이 과정에서 발생하는 재구성 오차를 활용하면 이상 탐지가 가능합니다. 정상 데이터만으로 학습한 모델은 비정상적인 패턴을 제대로 복원하지 못하기 때문입니다.

이번 강의에서는 오토인코더의 수학적 원리와 함께 Keras 구현 방법을 배우고, VAE(Variational Autoencoder)를 포함한 다양한 변형도 살펴봅니다. 제조 현장의 센서 데이터 이상 탐지에 직접 적용해 보겠습니다.
