# 17차시: 모델 평가와 반복 검증 - 마무리

이번 차시에서는 모델 평가와 반복 검증의 핵심 개념을 학습했습니다.

먼저 K-Fold 교차검증을 통해 단일 분할의 불안정성을 극복하고 모델 성능을 신뢰성 있게 측정하는 방법을 익혔습니다. 학습 곡선과 검증 곡선을 활용하여 과대적합과 과소적합을 진단하는 기법도 다루었습니다.

핵심 개념을 정리하면 다음과 같습니다. 정밀도는 예측한 양성 중 실제 양성 비율이고, 재현율은 실제 양성 중 예측 양성 비율입니다. F1 점수는 정밀도와 재현율의 조화 평균으로 불균형 데이터에서 특히 유용합니다. 교차검증은 데이터를 K개로 나누어 순환 평가하므로 더 안정적인 성능 추정이 가능합니다.

다음 18차시에서는 모델 설정값 최적화를 학습합니다. GridSearchCV와 RandomizedSearchCV를 활용하여 하이퍼파라미터 튜닝을 자동화하는 방법을 다룰 예정입니다. 수고하셨습니다.
