# 18차시: 모델 설정값 최적화 - 마무리

이번 차시에서는 하이퍼파라미터 튜닝의 핵심 개념과 실무 적용 방법을 학습했습니다.

핵심 내용을 정리하면 다음과 같습니다. 첫째, 하이퍼파라미터는 학습 전에 사람이 설정하는 값으로 모델 성능에 큰 영향을 미칩니다. 둘째, GridSearchCV는 모든 조합을 탐색하여 철저하지만 시간이 많이 소요됩니다. 셋째, RandomizedSearchCV는 랜덤 샘플링으로 효율적인 탐색이 가능합니다. 넷째, 실무에서는 Random Search로 넓은 범위를 먼저 탐색한 후 Grid Search로 정밀 탐색하는 2단계 전략이 효과적입니다.

이것으로 Part III 머신러닝 심화 과정을 마무리합니다. 다음 차시부터는 Part IV 시계열 분석이 시작됩니다. 19차시 "시계열 데이터 분석과 예측"에서는 시간 순서가 중요한 시계열 데이터의 특수성과 datetime 처리, 이동평균, 시차 변수 등 시계열 분석의 기초를 학습합니다.
