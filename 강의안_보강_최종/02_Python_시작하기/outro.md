# 2차시: Python 시작하기

## 마무리

이번 차시에서는 Python 프로그래밍의 기초를 학습했습니다.

먼저 Anaconda와 Jupyter Notebook으로 데이터 분석에 최적화된 개발 환경을 구축했습니다. Python의 5가지 핵심 자료형인 정수, 실수, 문자열, 리스트, 딕셔너리를 익히고, f-string을 활용한 데이터 포맷팅 방법을 배웠습니다. 조건문으로 품질 등급을 자동 판정하고, 반복문으로 센서 데이터를 분석하는 실습을 진행했습니다. 마지막으로 함수를 정의하여 재사용 가능한 코드를 작성하는 방법도 다루었습니다.

핵심 개념을 정리하면, Python은 직관적 문법으로 빠른 개발이 가능하고, Jupyter Notebook은 코드 실행 결과를 즉시 확인할 수 있어 데이터 분석에 적합합니다. if문과 for문은 데이터 처리 자동화의 기본이 됩니다.

다음 3차시에서는 NumPy와 Pandas 라이브러리를 활용하여 CSV 파일을 불러오고 실제 제조 데이터를 분석하는 방법을 학습합니다.
