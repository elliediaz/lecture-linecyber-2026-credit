# 21차시 강의 마무리

이번 차시에서는 Keras 프레임워크를 활용하여 MLP 모델을 구현하고 학습시키는 전체 과정을 실습했습니다. Sequential 모델로 신경망 구조를 설계하고, compile 메서드로 옵티마이저와 손실 함수를 설정한 뒤, fit 메서드로 학습을 수행하는 흐름을 익혔습니다.

핵심 개념을 정리하면, Dropout은 과적합을 방지하고 모델의 일반화 성능을 높이며, Early Stopping은 검증 손실이 개선되지 않을 때 학습을 자동으로 중단하여 최적의 가중치를 보존합니다. Batch Normalization은 각 층의 입력을 정규화하여 학습을 안정화하고 수렴 속도를 높입니다.

다음 22차시 딥러닝 응용: 오토인코더 기반 이상 탐지에서는 입력을 압축하고 복원하는 특수한 신경망 구조인 오토인코더를 학습합니다. 이를 통해 제조 현장의 비정상 패턴을 탐지하는 방법을 실습해 보겠습니다.
