# 27차시 도입

안녕하세요. 이번 차시는 전체 과정의 마지막 강의입니다. 지금까지 데이터 분석, 전처리, 머신러닝 모델 학습까지 진행해왔습니다. 이번 시간에는 학습된 모델을 실제로 사용할 수 있도록 서비스 형태로 배포하는 방법을 다룹니다.

구체적으로 Streamlit을 활용한 대화형 웹앱 구축, FastAPI를 통한 REST API 엔드포인트 구현, 그리고 Docker를 활용한 컨테이너 배포까지 학습합니다. 이전 차시에서 예측 모델과 API 개념을 익혔다면, 이번에는 실제 운영 환경에서 사용 가능한 서비스로 완성하는 것이 목표입니다.

모델이 아무리 뛰어나도 현장에서 활용할 수 없다면 의미가 없습니다. 품질 담당자가 직접 사용하는 웹 인터페이스와 MES 시스템이 자동으로 호출하는 API 서버를 함께 구축하여 완전한 ML 서비스를 완성해보겠습니다.
