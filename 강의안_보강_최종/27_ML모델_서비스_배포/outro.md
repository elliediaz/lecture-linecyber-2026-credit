# 27차시 마무리

이번 차시에서는 ML 모델을 실제 서비스로 배포하는 방법을 학습했습니다. Streamlit으로 사용자가 직접 조작하는 웹앱을 구축하고, FastAPI로 외부 시스템이 호출하는 API 엔드포인트를 구현했습니다. Pydantic을 통한 데이터 검증과 Docker를 활용한 컨테이너 배포까지 다루었습니다.

핵심은 배포 대상에 따른 도구 선택입니다. 사람이 직접 사용한다면 Streamlit 웹앱, 프로그램이 자동 호출한다면 FastAPI REST API를 선택합니다. 두 방식 모두 동일한 학습 모델을 활용하되, 인터페이스만 다르게 제공하는 것입니다.

27차시에 걸친 전체 과정을 통해 데이터 수집부터 전처리, 탐색적 분석, 머신러닝 모델 학습, 그리고 서비스 배포까지 데이터 분석의 전 과정을 완성했습니다. 앞으로는 클라우드 플랫폼 활용, API 보안 강화, 모델 모니터링과 재학습 자동화 등으로 학습을 확장해 나가시기 바랍니다. 수고하셨습니다.
