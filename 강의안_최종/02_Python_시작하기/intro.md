## 도입

안녕하세요. 이번 차시에서는 제조 AI 개발을 위한 핵심 도구인 Python 프로그래밍을 시작합니다.

지난 1차시에서 AI 윤리의 기본 원칙을 학습했습니다. 윤리적 기반 위에서 이제 본격적으로 AI 개발 도구를 익혀 나갑니다. Python은 AI와 데이터 분석 분야에서 90% 이상 사용되는 사실상의 표준 언어입니다. 직관적인 문법과 풍부한 라이브러리 생태계 덕분에 아이디어를 빠르게 구현할 수 있습니다.

이번 차시에서는 Anaconda와 Jupyter Notebook 환경을 구축하고, 정수, 실수, 문자열, 리스트, 딕셔너리 등 Python의 기본 자료형을 배웁니다. 또한 조건문과 반복문으로 데이터를 처리하고, 재사용 가능한 함수를 작성하는 방법을 실습합니다.

제조 현장의 생산량, 온도, 불량률 데이터를 직접 다루며 Python 기초를 체득해 보겠습니다.
