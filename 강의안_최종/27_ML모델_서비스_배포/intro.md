# 27차시 도입

지난 26차시에서 학습된 모델을 joblib과 pickle로 저장하는 방법을 익혔습니다. 이번 최종 차시에서는 저장된 모델을 실제 서비스로 배포하는 방법을 학습합니다.

먼저 REST API의 기본 개념과 HTTP 통신 방식을 이해하고, requests 라이브러리로 API 호출을 실습합니다. 이어서 Streamlit으로 품질 담당자가 직접 사용하는 웹앱을 구축하고, FastAPI로 MES 시스템이 자동 호출하는 API 엔드포인트를 구현합니다. 모델이 아무리 뛰어나도 현장에서 활용할 수 없다면 의미가 없습니다. 27차시 전체 과정의 마무리로, 데이터 수집부터 서비스 배포까지 완전한 ML 파이프라인을 완성해보겠습니다.
