# 26차시 마무리

이번 차시에서는 모델 해석부터 저장, 재활용까지 실무에 필요한 핵심 기술을 학습했습니다. Grad-CAM으로 CNN이 어느 영역을 보고 판단했는지 시각화하는 방법을 익혔고, TensorBoard와 Callbacks로 학습 과정을 체계적으로 추적하는 방법을 다루었습니다. EarlyStopping은 과적합을 방지하고, ModelCheckpoint는 최고 성능 모델을 자동 저장합니다.

joblib과 Pipeline을 활용하면 전처리와 모델을 하나의 객체로 관리할 수 있어 배포가 간편해집니다. 전이학습과 파인튜닝은 적은 데이터로도 높은 성능을 달성하는 핵심 기법입니다. 다음 27차시에서는 Streamlit과 FastAPI를 활용하여 학습된 모델을 실제 서비스로 배포하는 방법을 학습합니다.
