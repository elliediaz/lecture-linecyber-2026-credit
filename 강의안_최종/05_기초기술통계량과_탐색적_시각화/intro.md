# 5차시 도입

안녕하세요. 이번 차시부터 Part II '기초 수리와 데이터 분석' 파트가 시작됩니다. 지난 4차시에서는 공개 데이터셋을 활용하여 실제 데이터를 다루어 보았습니다. 이제 본격적으로 데이터를 분석하는 방법을 배워보겠습니다.

오늘은 기초 기술통계량과 탐색적 시각화를 학습합니다. 먼저 평균, 중앙값, 표준편차 등 데이터를 숫자로 요약하는 대표값과 산포도 개념을 다룹니다. 이어서 히스토그램, 상자그림(박스플롯), 산점도를 통해 데이터를 시각적으로 이해하는 방법을 실습합니다.

기술통계와 시각화는 데이터 분석의 첫걸음입니다. 수백, 수천 개의 데이터를 일일이 확인할 수 없으므로, 핵심 수치로 요약하고 그래프로 패턴을 파악하는 것이 분석의 출발점이 됩니다. 이번 차시에서 배우는 내용은 앞으로 모든 데이터 분석 과정의 기초가 됩니다.
