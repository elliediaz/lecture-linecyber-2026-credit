# 과정 오리엔테이션

## 스크립트 (약 1분 30초)

---

안녕하세요. "제조데이터를 활용한 AI 이해와 예측 모델 구축" 과정에 오신 것을 환영합니다.

이 과정은 **총 27차시**로 구성되어 있으며, Python 프로그래밍 기초부터 AI 모델 배포까지 전체 과정을 체험하실 수 있습니다.

---

### 학습 로드맵

**Part I. AI 윤리와 환경 구축 (1-4차시)**
- AI 윤리, Python 기초, 데이터 다루기

**Part II. 기초 통계와 데이터 분석 (5-11차시)**
- 통계량, 시각화, 가설검정, 전처리

**Part III. 머신러닝 (12-19차시)**
- 분류, 회귀, 클러스터링, 시계열 예측

**Part IV. 딥러닝 (20-25차시)**
- MLP, 오토인코더, CNN, RNN/LSTM

**Part V. 모델 해석과 서비스 배포 (26-27차시)**
- Grad-CAM, 파인튜닝, Streamlit, FastAPI

---

### 학습 방법

각 차시는 **25분 분량**으로, **이론과 실습이 함께** 진행됩니다. Jupyter Notebook 또는 Google Colab에서 직접 코드를 실행하며 학습합니다.

모든 실습에는 **실제 제조 데이터**를 활용합니다. Kaggle, UCI Repository, 공공데이터포털에서 제공하는 센서 데이터, 품질 데이터, 이미지 데이터로 현장과 유사한 문제를 해결합니다.

---

### 기대 성과

이 과정을 마치면:
- 데이터 수집부터 전처리, 분석까지 **데이터 분석 역량**을 갖추게 됩니다
- 머신러닝과 딥러닝 모델을 직접 구축하는 **AI 모델링 역량**을 확보합니다
- 학습된 모델을 웹 서비스로 배포하는 **실무 적용 역량**을 습득합니다

---

### 마무리

프로그래밍 경험이 없어도 괜찮습니다. 기초부터 차근차근 배워나가며, 마지막에는 직접 만든 AI 모델을 웹 서비스로 배포하는 경험을 하게 됩니다.

그럼 1차시 "AI 활용 윤리와 데이터 보호"에서 만나뵙겠습니다. 감사합니다.
