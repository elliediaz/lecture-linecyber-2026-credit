# 11차시 강의 소개

안녕하세요. 이번 시간은 Part II "기초 수리와 데이터 분석"의 마지막 차시입니다.

지난 10차시에서 스케일링과 원-핫 인코딩을 통해 제조 데이터 전처리를 마무리했습니다. 이제 정제된 데이터를 활용하여 지금까지 배운 모든 분석 기법을 종합적으로 적용해 봅니다.

이번 차시에서는 먼저 6-10차시에서 학습한 EDA 기법들을 실제 데이터에 체계적으로 적용하는 방법을 실습합니다. 이어서 단순회귀를 넘어 여러 변수를 동시에 활용하는 중다회귀 분석을 배우고, 이 과정에서 발생하는 다중공선성 문제를 VIF로 진단하는 방법을 익힙니다. 마지막으로 선형 모델이 비선형 관계나 복잡한 상호작용 앞에서 보이는 한계를 확인합니다.

이 차시가 Part II를 마무리하면서 Part III 머신러닝으로 나아가는 중요한 연결 고리가 됩니다.
