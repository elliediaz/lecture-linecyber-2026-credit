# 9차시 도입부

안녕하세요, 오늘은 제조 데이터 전처리의 첫 번째 시간입니다.

지난 8차시에서는 상관분석을 통해 변수 간의 관계와 데이터의 통계적 특성을 파악하는 방법을 배웠습니다. 이제 본격적으로 데이터의 품질을 개선하는 단계로 넘어갑니다.

데이터 분석 프로젝트에서 전처리가 전체 작업의 60~80%를 차지한다는 말을 들어보셨을 겁니다. 이는 과장이 아닙니다. 아무리 뛰어난 분석 기법이나 모델을 사용해도 입력 데이터의 품질이 나쁘면 결과도 나빠집니다. "Garbage In, Garbage Out"이라는 격언이 바로 이 원리를 설명합니다.

이번 차시에서는 결측치와 이상치라는 두 가지 핵심 문제를 다룹니다. 결측치는 센서 오류나 입력 누락으로 발생하는 비어있는 값이며, 이상치는 측정 오류나 실제 극단적 상황에서 나타나는 비정상적인 값입니다. IQR 방법과 Z-score 방법을 활용해 이상치를 탐지하고, 상황에 맞는 처리 전략을 선택하는 방법을 학습합니다.

이 기초를 탄탄히 다져야 다음 단계인 스케일링과 인코딩으로 나아갈 수 있습니다.
